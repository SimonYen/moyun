日语的第一课几乎都是「私は学生です」。这句话简单到让人以为没什么可讲的，但里面藏了三个后来会折磨你两年的东西：**は 和 が 的分工**、**です 的否定与过去**、以及**指示词的坐标感**。

这一讲把它们拆干净。

## 01 ～は～です：主题 + 判断

```
A は B です。   A 是 B。
```

「は」是**主题助词**，读作 **wa**。它提示「接下来我要说的是 A」。B 是判断内容，「です」是礼貌体的断定。

- 私は学生です。（我是学生）
- 明日は休みです。（明天休息）
- これは本です。（这是书）

注意第二句：`明日は休みです` 没有动词「是」，日语靠「です」完成判断。中文的「是」在日语里常常是**不出现**的——只有名词谓语句才用「です」，形容词谓语句直接用形容词。

## 02 ～ではありません：否定的三种说法

| 语气 | 形式 |
|---|---|
| 礼貌・正式 | ～ではありません |
| 礼貌・口语 | ～じゃありません |
| 常体・口语 | ～じゃない |

- 私は学生ではありません。（我不是学生）
- ここは教室じゃない。（这里不是教室）

「では」在口语里缩成「じゃ」，这个是所有缩约的总规律（后面「ては→ちゃ」「では→じゃ」都一样）。

过去式：`でした` / `ではありませんでした`。

## 03 ～ですか：疑问只加一个か

日语疑问句**不改语序**，句尾加「か」即可，而且**不用问号**（现代也常加）。

- あなたは学生ですか。（你是学生吗）
- これは何ですか。（这是什么）

回答时不说「はい、私は学生です」这种完整句，日常只说「はい、そうです」或「いいえ、違います」。

⚠️ 中文的「吗」对应「か」，但「か」不能用于**自问自答式的确认**（那种用「ね」）。

## 04 これ・それ・あれ：按「谁近」分三档

这是日语指示词的核心逻辑：**不是按「远近」，是按「跟谁说」**。

| 词 | 指代 | 场景 |
|---|---|---|
| これ | 离**说话人**近 | 我手上这本 |
| それ | 离**听话人**近 | 你手上那本 |
| あれ | 离**双方都远** | 墙上挂的那本 |
| どれ | 哪一个（三选一以上） | 疑问 |

特别提醒：当两人**面向同一方向**（比如一起看窗外），「これ」指离两人都近的，「あれ」指更远的。**位置关系会随视角变，但「これ=我这边」不变。**

- これは私の傘です。（这是我的伞）
- それは何ですか。（那是什么）
- あれは富士山です。（那是富士山）

## 05 この・その・あの：后面必须跟名词

「これ」系列可以独立当主语；「この」系列**是修饰语**，后面一定要接名词。

| 独立 | 修饰 |
|---|---|
| これ | この + 名词 |
| それ | その + 名词 |
| あれ | あの + 名词 |
| どれ | どの + 名词 |

- ✗ あのは富士山です
- ○ あの**山**は富士山です

「この本」「その人」——中文的「这本书」「那个人」在这里刚好一一对应。

## 06 ここ・そこ・あそこ：场所版

同样是三档 + 疑问：

- ここ（这里，我附近）
- そこ（那里，你附近）
- あそこ（那里，远处）
- どこ（哪里）

- ここは駅です。（这里是车站）
- トイレはどこですか。（厕所在哪）

![こそあど 体系](IMG_KOSOADO)

把这套「こ・そ・あ・ど」的规律记住，你能一次性推出十几个词：

| | こ（近我） | そ（近你） | あ（都远） | ど（疑问） |
|---|---|---|---|---|
| 物 | これ | それ | あれ | どれ |
| 修饰 | この | その | あの | どの |
| 场所 | ここ | そこ | あそこ | どこ |
| 方向 | こちら | そちら | あちら | どちら |
| 人（礼貌） | こちら | そちら | あちら | どなた |

## 07 疑问词家族：别只会「何」

- **だれ**（谁）/ **どなた**（哪位，礼貌）
- **何（なに / なん）**：接「です」时读「なん」→ 何ですか
- **どれ**：从三个以上里选一个
- **どの + 名词**：どれ 的修饰版
- **どこ**：地点

⚠️ 中文「哪个」不分独立和修饰，日语分得很清：

- どれがあなたの傘ですか。（哪个是你的伞）
- どの傘があなたのですか。（哪把伞是你的）

## 08 も：「也」和「都」

「も」替换「は/が/を」，表示「同样」。

- 私も学生です。（我也是学生）
- これも本です。（这也是书）

否定时 `も` + 否定 = 「也不」：

- 水も飲みません。（水也不喝）

⚠️ 还有一个隐藏用法：疑问词 + も + 否定 = **全否定**。

- だれも来ません。（谁都没来）
- 何も食べません。（什么都没吃）

这条 N5 就会遇到，但很多人到 N3 才真正用对。

## 09 の：所属、同位、替代

「の」最基础是「的」，但它有三种用法要分清：

| 用法 | 例 | 说明 |
|---|---|---|
| 所属 | 私の本 | 我的书 |
| 同位 | 友達の田中さん | 朋友田中（同位，不是「朋友的田中」） |
| 替代 | これは私のです | 这个是我的（代替「我的东西」） |

第三种非常常用。`赤いの`（红的那个）、`大きいの`（大的那个）——日语允许「形容词 + の」直接当名词用。

## 10 は 与 が 的第一次交锋

这是日语语法的第一大难题，N5 就出现，N1 还在纠。先给一个够用的版本：

> **は 提示「主题」——「关于 X，我要说……」**
> **が 标记「主语」——「谁做了这件事 / 谁是这样」**

三个最实用的区别：

1. **は 可以跨越句子范围**（「象は鼻が長い」——关于大象，鼻子长）
2. **が 用于新信息**（「だれが来ましたか」→「田中さんが来ました」）
3. **は 用于已知信息**（「田中さんは来ましたか」→「はい、来ました」）

初学阶段的安全策略：

- 说「A 是 B」→ `A は B です`
- 说「有某物/某人」→ `～が あります/います`
- 说「喜欢/讨厌/会/懂」→ 对象用 `が`（日本語**が**わかります）

## 本讲小结

名词句是日语的「静态骨架」：主题 + 判断。它没有时态、没有语态，所以最适合拿来把**助词**和**指示词**一次理清。

下一步就该动了：**动词句**。那也是「は/が/を/に/で」这五个助词真正开始分工的地方。

## 记忆卡片

> **指示词**：こ=我、そ=你、あ=都远、ど=问
> **この vs これ**：この 后面必须有名词
> **も + 否定**：也不 / 全都不
> **が 的对象**：わかる、できる、好き、ほしい
