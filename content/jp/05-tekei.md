如果把日语动词比作一台机器，那么「ます形」是外壳，「て形」是**接口**。所有需要「再接一个动作」的地方，都用这个接口。

这一讲聚焦一件事：**把「ています」的四张面孔认清楚**。很多学到 N2 的人还分不清「結婚しています」和「結婚しました」，其实问题就出在这一讲。

## 01 ます形的四种时态

| | 肯定 | 否定 |
|---|---|---|
| 现在・将来 | 行きます | 行きません |
| 过去 | 行きました | 行きませんでした |

日语的「现在时」其实兼表**将来**：`明日行きます`（明天去）。真正的「正在」要靠 ています。

还有一个常被忽略的常体（普通形）：

| | 肯定 | 否定 |
|---|---|---|
| 现在 | 行く | 行かない |
| 过去 | 行った | 行かなかった |

常体是**日记、小说、朋友间对话、以及所有从句**的默认形态。你在文章里看到的「〜した」「〜する」都是常体。

## 02 动词的三种「体」：这决定了て形怎么理解

日语动词按「动作性质」分三类，这直接决定 `ています` 的意思：

| 类型 | 例 | ています 的意思 |
|---|---|---|
| 持续动作 | 食べる、読む、走る | 正在吃 / 正在读 |
| 瞬间动作 | 死ぬ、結婚する、始まる、着く | 结果状态（已婚、已到） |
| 状态 | 知る、住む、持つ | 状态（知道、住在、拥有） |

这就是为什么：

- `食べています` = 正在吃
- `結婚しています` = 已婚（不是「正在结婚」）
- `知っています` = 知道（不是「正在知道」）

**中文母语者最容易错的就是这条**：把「結婚しています」理解成「正在结婚」。

## 03 て形的三大功能：并列、原因、接续

て形本身不表时态，它只是把两个动作「接」起来：

1. **并列・顺序**：朝起きて、顔を洗って、会社へ行きます。（起床、洗脸、去公司）
2. **原因・理由**：風邪を引いて、学校を休みました。（因为感冒，请假了）
3. **方式・状态**：歩いて行きます。（走着去）、喜んで受け取りました。

「て」的核心语感是：**前半句不结束，语气悬着，等后半句**。所以它不能用来表达「但是」这种转折——转折要用「が」「けれど」。

## 04 ～ています（进行）：正在做

```
动词て形 + います
```

- 今、雨が降っています。（现在正在下雨）
- 母は台所で料理を作っています。（妈妈正在厨房做饭）

口语里 `ています` 常缩成 `てる`：`何してる？`（你在干嘛）。

否定：`ていません`（没在做）。

## 05 ～ています（结果残留）：做完之后留下的状态

这是中文母语者最容易错的一类。瞬间动词 + ています = **动作完成后的状态**：

| 句子 | 意思 | 不是 |
|---|---|---|
| 結婚しています | 已婚 | ✗ 正在结婚 |
| 東京に着いています | 已经到了东京 | ✗ 正在到达 |
| 電気が消えています | 灯是关着的 | ✗ 正在熄灭 |
| 眼鏡をかけています | 戴着眼镜 | ✗ 正在戴 |

判断方法：**这件事如果「一秒钟就完成」，那 ています 就是结果状态。**

对比记忆：

- ご飯を食べています（正在吃——持续的）
- ご飯はもう作ってあります（饭已经做好了——てある，状态，后面讲）

## 06 ～ています（习惯・职业・居住）

第三种用法是「长期重复」或「持续的身份」：

- 毎朝ジョギングしています。（每天早上跑步）
- 銀行で働いています。（在银行工作）
- 大阪に住んでいます。（住在大阪）

这类句子换成「ます形」会变味：

- `毎朝ジョギングします` = 每天早上（打算）跑（强调习惯性动作本身）
- `毎朝ジョギングしています` = 我（一直在）保持这个习惯

**住む、働く、知る** 这三个词几乎固定用 ています。

## 07 ～てから：做完 A 再做 B

```
动词て形 + から
```

- 手を洗ってから、ご飯を食べます。（洗手之后吃饭）
- 大学を卒業してから、ずっと東京にいます。（毕业之后一直在东京）

和「～たあとで」的区别：

| 形式 | 语感 |
|---|---|
| てから | 强调**顺序的先后**，A 是 B 的前提 |
| たあとで | 单纯说「之后」，A 和 B 关系可以很松 |

## 08 ～てください / ～ないでください：请 / 请不要

- ここに名前を書いてください。（请在这里写名字）
- 写真を撮らないでください。（请不要拍照）

礼貌升级（N4 会细讲）：

| 礼貌度 | 形式 |
|---|---|
| 一般 | ～てください |
| 较礼貌 | ～てくださいませんか |
| 很礼貌 | ～ていただけませんか |

`～ないでください` 的柔和版是 `～ないようにしてください`（请尽量别……）。

## 09 ～てもいいです / ～てはいけません：可以 / 不可以

- ここに座ってもいいですか。（可以坐这里吗）
- ここでタバコを吸ってはいけません。（这里不可以抽烟）

三个相关形式一次记清：

| 形式 | 意思 |
|---|---|
| ～てもいい | 可以做（许可） |
| ～てはいけない | 不可以做（禁止） |
| ～なくてもいい | 不做也行（不必） |

⚠️ 疑问句 `～てもいいですか` 的回答：
- 肯定：はい、いいですよ / どうぞ
- 否定：いいえ、ちょっと……（日本人很少直接说「だめです」）

## 10 ～ながら：一边……一边……

```
动词ます形（去ます） + ながら
```

- 音楽を聞きながら、勉強します。（边听音乐边学习）
- 彼は働きながら、大学に通っている。（他一边工作一边上大学）

**三个硬性限制**：

1. 主句和从句必须是**同一个人**的动作
2. 主句必须是**主要动作**（ながら 的部分是附带动作）
3. 不能是瞬间动词（✗ 起きながら）

---

## 本讲小结

て形是日语里出现频率最高的形态之一。它的三种用法可以用一句话概括：

> **て = 「还没说完」**。并列、原因、方式，都是「前半句还没落地，后半句才是重点」。

而 `ています` 的四张面孔，本质取决于**动词本身的体**：

| 动词类型 | ています 意思 |
|---|---|
| 持续 | 正在做 |
| 瞬间 | 做完后的状态 |
| 状态 | 一直保持 |
| 反复 | 习惯/职业 |

## 记忆卡片

> **結婚しています = 已婚**，不是正在结婚
> **知っています / 住んでいます / 働いています** 固定用ています
> **てもいい**（可以）／**てはいけない**（不可以）／**なくてもいい**（不必）
> **ながら**：同一人、主次分明、非瞬间动词
