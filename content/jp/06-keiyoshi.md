日语形容词分两类，这个大家都知道。但很多人学到 N4 才发现：**它们在句子里「怎么变形」完全是两套规则**，而且修饰名词、修饰动词、变成名词，都不能互换。

这一讲把两套系统并排放，让区别一眼可见。

## 01 怎么分：看原形，别靠翻译

| | 特征 | 例 |
|---|---|---|
| い形容词（一类） | 原形以 **い** 结尾 | 高い、暑い、面白い、忙しい |
| な形容词（二类） | 原形不以 い 结尾 | 静か、きれい、元気、便利、有名 |

唯一需要警惕的陷阱：**以「い」结尾但是な形容词**。

- きれい（漂亮）
- 嫌い（讨厌）
- 有名（ゆうめい，有名）
- 特別（とくべつ）

这四个长得像い形容词，实际全是な形容词：`きれいな人`（✓）不是 `きれい人`（✗）。

> 判定方法：能不能直接加「な」修饰名词。能，就是な形容词。

## 02 い形容词的四态活用

| | 形式 | 例（高い） |
|---|---|---|
| 现在肯定 | ～い | 高い（です） |
| 现在否定 | ～くない | 高くない（です） |
| 过去肯定 | ～かった | 高かった（です） |
| 过去否定 | ～くなかった | 高くなかった（です） |

更礼貌的否定可以说 `高くありません`、`高くありませんでした`——注意这里的「く」不能丢。

变化的关键是：**い 变成 く**，然后接ない/なかった。

## 03 な形容词的四态活用

| | 形式 | 例（静か） |
|---|---|---|
| 现在肯定 | ～です | 静かです |
| 现在否定 | ～ではありません / じゃない | 静かじゃないです |
| 过去肯定 | ～でした | 静かでした |
| 过去否定 | ～ではありませんでした | 静かじゃなかったです |

な形容词的活用**和名词完全一样**——这是最好用的记忆点：

```
学生です    → 静かです
学生じゃない → 静かじゃない
学生だった   → 静かだった
```

## 04 修饰名词：い直接，な加な

| 类型 | 规则 | 例 |
|---|---|---|
| い形容词 | 直接接 | 高い**建物** |
| な形容词 | + な | 静か**な**町 |
| 名词 | + の | 日本の町 |

❌ 高**な**建物　❌ 静か町　❌ 静かの町

这三个错误是中文母语者最常见的一类，因为中文的「的」是通用的，而日语分了三种。

## 05 て形并列：高くて / 静かで

想并列两个形容词：

- この店は安**くて**、おいしいです。（这家店又便宜又好吃）
- この町は静か**で**、きれいです。（这个小镇又安静又漂亮）

规则：

| 类型 | て形 |
|---|---|
| い形容词 | い → **くて** |
| な形容词 | + **で** |
| 名词 | + **で** |

⚠️ `いい` 的て形是 `よくて`。

## 06 副词化：修饰动词

| 类型 | 副词形 | 例 |
|---|---|---|
| い形容词 | い → **く** | 早**く**起きる（早起） |
| な形容词 | + **に** | 静か**に**歩く（安静地走） |

- もっと**早く**来てください。（请早点来）
- ゆっくり**静かに**話してください。（请安静地慢慢说）

## 07 名词化：把形容词变成「程度」

| 类型 | 名词形 | 意思 |
|---|---|---|
| い形容词 | い → **さ** | 高さ（高度）、深さ（深度） |
| な形容词 | + **さ** | 静かさ（安静程度）、便利さ |

「さ」表示**可测量的程度**；还有一个「み」表示**感觉/状态**，用得少（重み、甘み、面白み）。

- この山の**高さ**は 3000 メートルです。（这座山的高度是 3000 米）
- 富士山の**美しさ**は言葉にできない。（富士山的美无法用语言形容）

## 08 なる：状态变化

```
い形容词：い → く + なる
な形容词：+ に + なる
名词：    + に + なる
```

- だんだん**暑く**なります。（渐渐变热）
- 部屋が**きれいに**なりました。（房间变干净了）
- 来年、**大学生に**なります。（明年成为大学生）

⚠️ 中文说「变热了」，日语必须把「く」加上，不能省。

## 09 三个不规则：いい、ない、多い

**いい** 的活用全部走 **よい**：

| | 形式 |
|---|---|
| 否定 | よくない |
| 过去 | よかった |
| て形 | よくて |
| 副词 | よく |

`よかった` 是日本人最常说的一句话之一：`よかった！`（太好了）。

**ない** 本身就是い形容词，过去形是 `なかった`（不是「ないかった」）。

**多い / 少ない** 不能直接修饰名词表数量：

- ✗ 多い人が来た
- ○ 多くの人が来た（很多人来了）

这是 N4 考试的高频陷阱。

## 10 感情形容词与「が」

表示**感觉、感情、能力**的形容词，对象用「が」而不是「を」：

| 句型 | 例 |
|---|---|
| ～が好きです | 私は猫**が**好きです |
| ～が嫌いです | 虫**が**嫌いです |
| ～がほしいです | 新しい車**が**ほしいです |
| ～が怖いです | 犬**が**怖いです |
| ～が上手です | 彼は料理**が**上手です |
| ～がわかります | 日本語**が**わかります |

⚠️ 还有一条：**感情形容词只能用于第一人称**。

- ○ 私はうれしいです。（我高兴）
- ✗ 彼はうれしいです。（他高兴）→ 要用 `彼はうれし**そう**です`

这条规则叫「感情形容词的人称限制」，是日语一个很深的特征：**你不能替别人断言他的内心**。

## 记忆卡片

> **陷阱四兄弟**：きれい・嫌い・有名・特別 都是な形容词
> **いい → よい**：よくない、よかった、よくて
> **多い** 修饰名词要变「多くの」
> **感情形容词**只用于自己；说别人要加「そう」
