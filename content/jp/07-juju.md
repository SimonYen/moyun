中文一个「给」字，日语要分三个词。这不是日语啰嗦，而是日语**必须标记「视点」**——你必须站在某个人的位置上说话。

这一讲把那场「视角战争」讲明白。它也是后面 てあげる / てもらう / てくれる 的基础，而那一组是日语最温柔也最容易错的部分。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | あげる | 我给（或第三方向第三方） |
| 02 | もらう | 我得到 |
| 03 | くれる | 别人给我 |
| 04 | 三者的视角图 | 东西往哪边流 |
| 05 | 敬语版 | さしあげる・いただく・くださる |
| 06 | てあげる | 我为你做 |
| 07 | てもらう | 我请你做 |
| 08 | てくれる | 你为我做 |
| 09 | 请求的礼貌阶梯 | 从 てください 到 ていただけませんか |
| 10 | 三个高频错误 | 别对上司用あげる |

## 01 あげる：东西从我这边往外流

```
A は B に 物を あげる
```

- 私は田中さんに本をあげました。（我给了田中一本书）
- 田中さんは佐藤さんに本をあげました。（田中给了佐藤一本书）

使用条件：**A 不能是「我」，B 不能是「我」**（否则该用 くれる 或 もらう）。

- A 是我 → 用 あげる
- A 是别人、B 是别人 → 也用 あげる
- A 是别人、B 是我 → **不能用あげる**，要用 くれる

## 02 もらう：东西流到我这边

```
A は B に／から 物を もらう
```

- 私は田中さんに本をもらいました。（我从田中那儿得到一本书）
- 田中さんは佐藤さんから本をもらいました。（田中从佐藤那儿得到一本书）

「に」和「から」都可以标记给予者，但：

| 助词 | 语感 |
|---|---|
| に | 中性，「从某人那里」 |
| から | 强调起点，「从……那里」（更常用，也更清楚） |

## 03 くれる：别人给我

```
A は 私に 物を くれる
```

- 田中さんは私に本をくれました。（田中给了我一本书）
- 父は私に自転車をくれました。（爸爸给了我一辆自行车）

**「私」常常省略**：`田中さんが本をくれた`。因为「くれる」本身就蕴含「给我」。

⚠️ 「私」不只指自己，还包括**我方**：家人、自己公司的人。

- 先生は**妹に**本をくれました。（老师给了我妹妹一本书）

## 04 三者的视角图

![授受三视点](IMG_JUJU)

一句话记住：

> **あげる = 我往外给；くれる = 别人往我这给；もらう = 我从别人那得。**

同一个事实，可以有两种说法，取决于你站在谁的位置：

| 说法 | 视点 |
|---|---|
| 田中さんが私に本をくれた | 站在我的位置（受惠） |
| 私は田中さんに本をもらった | 站在我的位置（主动取得） |

两个句子都是「我」的视角，但**くれる 强调对方的好意，もらう 强调我接受的行为**。

## 05 敬语版：对长辈怎么说

| 普通 | 敬语 | 用于 |
|---|---|---|
| あげる | さしあげる | 我给长辈/上级 |
| もらう | いただく | 我从长辈处得到 |
| くれる | くださる | 长辈给我 |

⚠️ **`さしあげる` 现在很少用**，因为它带着「施恩」的味道。对上级说「这本给您」更自然的是：

- どうぞ、お使いください。（请用）
- これ、よろしかったら。（这个，如果不嫌弃的话）

反而是 `いただく` 和 `くださる` 用得很多：

- 先生から本を**いただきました**。（从老师那里得到了书）
- 先生が本を**くださいました**。（老师给了我书）

## 06 てあげる：我为你做

```
动词て形 + あげる
```

- 荷物を持ってあげましょうか。（我帮你拿行李吧）
- 妹に自転車を教えてあげた。（我教了妹妹骑车）

⚠️ 这个是**最容易冒犯人的句型**。因为它暗示「我在施恩于你」。对上级、对不熟的人，绝对不要用。

安全的替代：

- お手伝いしましょうか。（我帮您吧）
- ～ましょうか（要不要我……）

## 07 てもらう：我请你做（我受益）

```
动词て形 + もらう
```

- 田中さんに日本語を教えてもらいました。（我请田中教我日语）
- 友達に写真を撮ってもらった。（我请朋友帮我拍了照）

这条的核心是：**动作是别人做的，但受益者是我**。所以它天然带着感谢。

## 08 てくれる：你为我做（我感谢你）

```
动词て形 + くれる
```

- 田中さんが日本語を教えてくれました。（田中（主动）教了我日语）
- 母が弁当を作ってくれた。（妈妈给我做了便当）

和 てもらう 的区别：

| 句子 | 语感 |
|---|---|
| 教えてもらった | 我请他教的（有「请求」的痕迹） |
| 教えてくれた | 他主动教我的（强调好意） |

## 09 请求的礼貌阶梯

日语请求别人做事，靠**降低自己的位置**来表达礼貌：

| 礼貌度 | 形式 | 场景 |
|---|---|---|
| ★☆☆ | ～てください | 一般、同级 |
| ★★☆ | ～てくれませんか | 稍礼貌 |
| ★★☆ | ～てもらえませんか | 稍礼貌（我受益） |
| ★★★ | ～ていただけませんか | 很礼貌 |
| ★★★★ | ～ていただけないでしょうか | 商务、正式 |

实际用法：

- ちょっと待って**ください**。（请稍等）
- ちょっと待って**もらえますか**。（能等一下吗）
- 少々お待ち**いただけますか**。（能请您稍候吗）

## 10 三个高频错误

**错误 1：对我用あげる**

- ✗ 田中さんは私に本をあげました
- ○ 田中さんは私に本を**くれました**

**错误 2：对上司用 てあげる**

- ✗ 部長、資料を持ってあげます
- ○ 部長、資料をお持ちしましょうか

**错误 3：主语搞混**

- 「我请田中帮忙」→ 私は田中さんに**手伝ってもらった**
- 「田中帮我」→ 田中さんが**手伝ってくれた**

两者都对，但前者是「我主动请他」的视角，后者是「他主动帮我」的视角。**日语句子的视点必须统一**——这是日语写作最重要的一条隐形规则。

## 本讲小结

| 方向 | 主动方 | 动词 |
|---|---|---|
| 我给（外流） | 我 / 第三方 | あげる |
| 我得到（内流） | 我 | もらう |
| 别人给我（内流） | 别人 | くれる |

て形版本完全同构：てあげる / てもらう / てくれる。

## 记忆卡片

> **あげる** 我→别人；**くれる** 别人→我；**もらう** 我←别人
> **てあげる** 别对上级用
> **てもらう** 有请求痕迹；**てくれる** 是对方主动
> **视点必须统一**，一句话里不能来回跳
