「如果」是日语里最难翻译的一个词。因为日语把「假设」拆成了四种完全不同的逻辑：

- 自然的因果（**と**）
- 假设的条件（**ば**）
- 完成之后的条件（**たら**）
- 接着对方话题的条件（**なら**）

很多人学到 N2 还是靠语感乱用，其实只要抓住**四者各自守的规矩**，就能推出来。

## 01 と：一……就……（必然的因果）

```
动词辞书形 + と
```

- 春になる**と**、桜が咲きます。（一到春天，樱花就开）
- このボタンを押す**と**、お釣りが出ます。（按这个按钮，零钱就会出来）
- 右へ曲がる**と**、駅が見えます。（向右转，就能看到车站）

「と」的核心是**必然・恒常**：不是「如果」，而是「每次都是这样」。所以它最适合：

- 自然现象、机械操作、指路、习惯性结果

## 02 ば：只要……就……（假设的条件）

```
动词：ます形去ます + れば（書けば）
い形容词：い → ければ（高ければ）
な形容词/名词：+ なら（静かなら / 学生なら）
```

- お金があれ**ば**、旅行に行きます。（如果有钱，就去旅行）
- 安けれ**ば**買います。（便宜的话就买）
- 静か**なら**、ここに引っ越したい。（安静的话，想搬到这里）

「ば」的特点：**强调「条件成立」本身**，条件满足，结果自然来。它常带一点「必要条件」的意味：

- 練習しなければ、上手にならない。（不练习就不会变好）

## 03 たら：……了的话（完成之后）

```
动词た形 + ら
```

- 家に着い**たら**、電話してください。（到了家给我打电话）
- 雨が降っ**たら**、中止します。（下雨的话就中止）
- 安かっ**たら**買います。（便宜的话（我）买）

「たら」的核心是**「A 完成了，然后 B」**——先有 A 的实现，才有 B。它是四个里**最口语、最万能**的。

⚠️ 注意「たら」是从「た」来的，所以它天然带**完了**的语感：`着いたら` 是「到了之后」，不是「如果到」。

## 04 なら：提到……的话（承接话题）

```
名词 + なら
动词/形容词普通形 + なら
```

- 日本の料理**なら**、寿司がいいです。（说到日本料理，寿司不错）
- あなたが行く**なら**、私も行きます。（你去的话我也去）
- 東京**なら**、あの店がおいしいですよ。（要是东京的话，那家店好吃）

「なら」的独特之处：**它是「承接对方刚说的话」**。所以它常出现在对话里：

> A：旅行に行きたいです。
> B：旅行**なら**、京都はどうですか。

用中文说就是「**说到……的话**」，而不是「如果」。

## 05 四者对比表

![条件四兄弟对比](IMG_JOKEN)

| | 接续 | 核心语感 | 典型 |
|---|---|---|---|
| と | 辞书形 | 必然・恒常 | 春になると咲く |
| ば | 假定形 | 条件的成立 | お金があれば行く |
| たら | た形 | 完了之后 | 着いたら電話する |
| なら | 名词/普通形 | 承接话题 | 東京ならあの店 |

## 06 と 的禁区：后面不能接意志・命令・请求

这是「と」最重要的限制：

- ✗ 家に着く**と**、電話してください
- ○ 家に着い**たら**、電話してください

因为「と」表示必然结果，而「请打电话」不是自然发生的结果。同理：

| 后句 | 能否用 と |
|---|---|
| 自然现象 | ✓ |
| 自动发生 | ✓ |
| 意志（～よう） | ✗ |
| 命令（～なさい） | ✗ |
| 请求（～てください） | ✗ |

## 07 ば 的禁区：后面不能是过去事实

「ば」表示假设，所以不能说「已经发生的事」：

- ✗ あの時、お金があれ**ば**、買った（「买った」是过去事实）
- ○ あの時、お金があっ**たら**、買った

还有个小坑：`ば` 后面接同一主语的意志时，语感很别扭（`私が行けば、私も…`），要换 `たら`。

## 08 たら 的万能化：口语里它几乎通吃

现代日语口语中，`たら` 已经吞掉了大部分场景：

| 场景 | 书面 | 口语 |
|---|---|---|
| 恒常 | 春になると | 春になったら |
| 假设 | お金があれば | お金があったら |
| 承接 | 東京なら | 東京だったら |

**实用建议**：不确定的时候用「たら」，90% 的场景不会错。只有两个例外——

1. 指路、机械说明（用「と」更自然）
2. 承接对方话题（用「なら」更地道）

## 09 なら 的两种面孔

**面孔一：承接话题**

> A：日本語を勉強したいです。
> B：日本語**なら**、この本がいいですよ。

**面孔二：假设立场（「既然你说……」）**

> あなたが行く**なら**、私も行きます。
> （既然你要去，那我也去）

第二种常带一点「根据你说的条件，我做出判断」的味道。这也是它和「たら」的微妙差别：`たら` 是「发生之后」，`なら` 是「你说的情况成立的话」。

## 10 四个实战场景：用对一次就记住

**场景 A：指路**
> この道をまっすぐ行く**と**、駅があります。
（用と，因为是指路的必然）

**场景 B：约时间**
> 仕事が終わっ**たら**、連絡します。
（用たら，因为要先完成工作）

**场景 C：给建议**
> 安けれ**ば**、買います。
（用ば，因为是「条件成立」的判断）

**场景 D：接话**
> 京都**なら**、春がいいですよ。
（用なら，因为承接对方说的地点）

## 本讲小结

判断顺序建议：

1. 后句是命令/请求/意志？→ 排除 と
2. 说的是「已经发生」的过去？→ 排除 ば
3. 是「承接对方说的内容」？→ 用 なら
4. 其余不确定的 → 用 たら

## 记忆卡片

> **と** 必然（不能用命令请求）
> **ば** 条件成立（不能接过去事实）
> **たら** 完成之后（最万能）
> **なら** 承接话题（「说到……的话」）
