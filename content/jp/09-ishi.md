日语的意愿表达有一条铁律：**你只能断言自己的内心**。所以「想」分成了两套：

- 说自己 → たい / ほしい
- 说别人 → たがる / ほしがる / そう

这不是语法细节，而是日语的**世界观**：内心是私密的，别人只能从外部观察。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～たい | 我想做 |
| 02 | ～たがる | 他想做 |
| 03 | ほしい / ほしがる | 想要东西 |
| 04 | ～つもり | 打算（有计划） |
| 05 | 意志形 + と思う | 我打算（当下决定） |
| 06 | ～ましょう / ～ましょうか | 我来 / 一起吧 |
| 07 | ～ませんか | 要不要（邀请） |
| 08 | ～ことにします | 我决定 |
| 09 | ～ことになります | 被决定 |
| 10 | ～てほしい | 希望你做 |

## 01 ～たい：我想做

```
动词ます形（去ます） + たい
```

- 日本へ行き**たい**です。（我想去日本）
- 何が食べ**たい**ですか。（你想吃什么）

⚠️ 「たい」本身是**い形容词**，所以：

| 形式 | 例 |
|---|---|
| 否定 | 行き**たくない** |
| 过去 | 行き**たかった** |
| て形 | 行き**たくて** |

主语只能是**说话人自己**（或在疑问句中问对方）。`彼は行きたいです` 是错的。

## 02 ～たがる：他想做

```
动词ます形（去ます） + たがる
```

- 弟はゲームをし**たがって**います。（弟弟想玩游戏）
- 田中さんは新しい車を買い**たがって**いる。（田中想买新车）

「たがる」是**五段动词**，所以常用 `たがっている` 表示「一直想」。

还有一个更客观的说法：`～たいようです` / `～たいと思っているようです`（看起来他想）。

## 03 ほしい / ほしがる：想要东西

| 人称 | 形式 | 例 |
|---|---|---|
| 我 | ～がほしい | 新しい車がほしい |
| 他 | ～をほしがる | 彼は車をほしがっている |

⚠️ 注意助词变化：`ほしい` 用 **が**，`ほしがる` 用 **を**。因为 ほしい 是形容词，ほしがる 是动词。

还有「てほしい」：

- 早く来**てほしい**です。（希望你早点来）

## 04 ～つもり：打算（有具体计划）

```
动词辞书形 / ない形 + つもり
```

- 来年、日本へ行く**つもり**です。（打算明年去日本）
- お酒は飲まない**つもり**です。（打算不喝酒）

`つもり` 的关键：**是「已经想好的计划」**，不是临时决定。

否定有两种，意思完全不同：

| 形式 | 意思 |
|---|---|
| 行かないつもりです | 打算不去 |
| 行くつもりはありません | 没有去的打算（更强的否定） |

## 05 意志形 + と思う：我打算（当下决定）

```
意志形 + と思う / と思っている
```

- 明日から早く起き**よう**と思います。（我打算从明天开始早起）
- 大学院に進**もう**と思っています。（我一直在考虑读研）

区别：

| 形式 | 语感 |
|---|---|
| ～ようと思う | 当下做出的决定 |
| ～ようと思っている | 已经持续想了一段时间 |

## 06 ～ましょう / ～ましょうか：我来 / 一起吧

| 形式 | 意思 |
|---|---|
| ～ましょう | 我们一起做吧（提议） |
| ～ましょうか | 我来帮你做吧？（主动请缨） |

- 一緒に行き**ましょう**。（一起去吧）
- 荷物を持ち**ましょうか**。（我帮你拿行李吧？）

第二句是日语里**最安全的「帮忙」表达**——比 `てあげる` 礼貌得多。

## 07 ～ませんか：要不要（邀请）

- 一緒に昼ご飯を食べ**ませんか**。（要不要一起吃午饭）

`ませんか` 比 `ましょう` 更礼貌，因为它把决定权留给对方：

| 形式 | 语感 |
|---|---|
| 食べましょう | 我们吃吧（已经假定对方同意） |
| 食べませんか | 要不要吃（更礼貌） |

拒绝时不用「いいえ」，而说：

- すみません、ちょっと……（抱歉，有点……）
- 今日はちょっと都合が悪いんです。（今天不太方便）

## 08 ～ことにします：我决定

```
动词辞书形/ない形 + ことにする
```

- 毎日運動する**ことにしました**。（我决定每天运动）
- タバコをやめる**ことにします**。（我决定戒烟）

这是**自己做的决定**，主语是我。

## 09 ～ことになります：被决定

```
动词辞书形/ない形 + ことになる
```

- 来月、大阪へ転勤する**ことになりました**。（下个月被调到大阪）
- 会議は来週**ということになりました**。（会议定在下周了）

区别很重要：

| 形式 | 谁决定 |
|---|---|
| ことにします | 我决定（主动） |
| ことになります | 被决定 / 组织决定（被动） |

日语职场里 `ことになりました` 极常用，因为它**隐去决定者**，避免显得独断。

## 10 ～てほしい：希望你做

```
动词て形 + ほしい
```

- もう少し静か**にしてほしい**です。（希望你们安静一点）
- 誰にも言わ**ないでほしい**。（希望你别告诉任何人）

否定是 `ないでほしい`。这个句型带一点**请求+抱怨**的味道，用的时候注意语气。

更礼貌的替代：

- ～ていただけるとありがたいです（如果能……就太好了）

## 本讲小结

| 意思 | 自己 | 别人 |
|---|---|---|
| 想做 | ～たい | ～たがる |
| 想要 | ～がほしい | ～をほしがる |
| 打算 | ～つもり / ～ようと思う | ～つもりらしい |
| 决定 | ～ことにする | ～ことになる |

## 记忆卡片

> **たい・ほしい 只能说自己**；说别人用 たがる・ほしがる
> **つもり** 是已有计划；**ようと思う** 是当下决定
> **ことにする** 我决定；**ことになる** 被决定
> **ましょうか** 是最安全的「帮忙」说法
