日语表达「能 / 必须 / 可以 / 不可以」的方式，比中文啰嗦，但逻辑非常清楚：**每个意思都有固定形式，不能混**。

这一讲把四组并排放。学完这一讲，N4 的「语法骨架」就完整了。

## 01 可能形的三种构成

| 类型 | 规则 | 例 |
|---|---|---|
| 五段 | 词尾 → え段 + る | 書く→書ける、飲む→飲める |
| 一段 | 去る + られる | 食べる→食べられる |
| する | できる | する→できる |
| 来る | こられる | 来る→こられる |

⚠️ 可能形**本身是一段动词**，所以继续变形时按一段走：

- 書ける → 書けます、書けて、書ければ

## 02 を → が：可能句的助词会变

这是 N4 考试高频点。动词变成可能形后，原来标记宾语的「を」通常换成「が」：

- 日本語**を**話します → 日本語**が**話せます
- お酒**を**飲みます → お酒**が**飲めます

不过现代日语里「を」也没错，尤其是句子较长时：

- 日本語**を**話せます（也完全可以）

**规律**：短句用「が」更自然，长句保留「を」更清楚。

## 03 ら抜き言葉：口语里的「食べれる」

一段动词的可能形本该是「食べられる」，但口语里常省略「ら」：

| 标准 | 口语（ら抜き） |
|---|---|
| 食べられる | 食べれる |
| 見られる | 見れる |
| 来られる | 来れる |

这是**口语化现象**，年轻人日常几乎都用。但：

- 商务文书、考试作文 → 用标准形
- 日常会话 → 两种都行

顺带一提，`食べられる` 有**三个意思**：可能、被动、敬语。要靠语境分辨。

## 04 見える / 聞こえる：自然 vs 有能力

这是日语一个很精细的区分：

| 词 | 意思 | 例 |
|---|---|---|
| 見える | 自然映入眼帘 | 窓から海が見える |
| 見られる | 有条件能看到 | この映画はネットで見られる |
| 聞こえる | 自然传入耳朵 | 鳥の声が聞こえる |
| 聞ける | 有条件能听到 | このラジオで音楽が聞ける |

⚠️ 这两个词**不能再加「られる」**：

- ✗ 見えられる
- ✗ 聞こえられる

## 05 ～ことができる：更正式的「能」

```
动词辞书形 + ことができる
```

- ここで写真を撮る**ことができます**。（这里可以拍照）
- 日本語を話す**ことができますか**。（你会说日语吗）

和可能形的区别：

| 形式 | 语感 |
|---|---|
| 可能形 | 简短、日常 |
| ことができる | 稍正式、书面、强调「这件事本身可行」 |

在告示、说明书里几乎都用 `ことができる`。

## 06 ～なければならない：必须（书面）

```
动词ない形（去ない） + なければならない
```

- 毎日薬を飲ま**なければなりません**。（必须每天吃药）
- 宿題をやら**なければならない**。（必须做作业）

更口语的缩约：

| 形式 | 语气 |
|---|---|
| なければならない | 标准、书面 |
| なくてはならない | 同上，略柔和 |
| なきゃ | 极口语 |
| ないと | 极口语 |

`なきゃ` 和 `ないと` 在日剧里出现频率极高，但正式场合不能用。

## 07 ～なくてはいけない / ないといけない：必须（口语）

- 早く帰ら**なくてはいけません**。（必须早点回去）
- 明日までに提出し**ないといけない**。（必须在明天之前提交）

和 `なければならない` 的差别**极小**，主要在使用场景：

| 形式 | 常用场景 |
|---|---|
| なければならない | 规则、义务、文章 |
| なくてはいけない | 个人义务、会话 |
| ないといけない | 会话、略带紧迫 |

## 08 ～なくてもいい：不必

```
动词ない形（去ない） + なくてもいい
```

- 明日は来**なくてもいい**です。（明天不用来）
- 全部覚え**なくてもいい**。（不用全部记住）

⚠️ 这个和 `てはいけない` 只差一点，但意思天差地别：

| 形式 | 意思 |
|---|---|
| なくてもいい | 不必（不做也行） |
| てはいけない | 不可以（不能做） |

初学者最常犯的错就是把「不必」说成「不可以」。

## 09 ～てはいけない：不可以

```
动词て形 + はいけない
```

- ここで写真を撮っ**てはいけません**。（这里不能拍照）
- 嘘をつい**てはいけない**。（不可以说谎）

口语形式：

| 形式 | 语气 |
|---|---|
| てはいけない | 标准 |
| てはだめ（だ） | 会话，较强 |
| ちゃだめ | 极口语 |

## 10 禁止的强度阶梯

日语表达「别做」有很多层次，选错会很失礼：

| 强度 | 形式 | 场景 |
|---|---|---|
| ★☆☆ | ～ないでください | 一般请求 |
| ★☆☆ | ～ないほうがいいです | 建议（软） |
| ★★☆ | ～ないようにしてください | 提醒、通知 |
| ★★★ | ～てはいけません | 明确禁止 |
| ★★★★ | ～べからず | 告示、标语（古风） |
| ★★★★★ | ～な | 强烈禁止（粗） |

告示上的写法通常是：

- 立入禁止（たちいりきんし）
- ここにゴミを捨てないでください
- 用事のある方以外入らないでください

## 本讲小结

| 中文 | 日语 |
|---|---|
| 能 | 可能形 / ことができる |
| 必须 | なければならない / なくてはいけない |
| 不必 | なくてもいい |
| 不可以 | てはいけない |

这四个构成一个完整的**情态四边形**，加上「たい（想）」，就是日语表达「意愿与义务」的全部基本手段。

## 记忆卡片

> **可能形**：五段换え段、一段加られる、する→できる
> **を→が**：日本語が話せる
> **なくてもいい** = 不必；**てはいけない** = 不可以
> **見える・聞こえる** 不能再加られる
