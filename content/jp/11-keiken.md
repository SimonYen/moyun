N5 的句子都是「一个事实」。N4 开始出现**嵌套**：一句话里套另一句话。这就是「从句」。

日语从句跟中文最大的不同是：**从句里的动词一律用常体**，而且**必须把从句「包」起来**才不会歧义。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～たことがある | 曾经做过 |
| 02 | たことがある vs た | 经验 vs 事实 |
| 03 | ～たり～たりする | 时而这样时而那样 |
| 04 | ～し～し | 列举理由 |
| 05 | ～という | 叫做……的 |
| 06 | ～と思う | 我认为 |
| 07 | ～と言う / と聞く | 说 / 听说 |
| 08 | ～かどうか | 是否 |
| 09 | 疑问词 + か | 间接疑问 |
| 10 | ～のだ / ～んです | 解释说明 |

## 01 ～たことがある：曾经做过

```
动词た形 + ことがある
```

- 富士山に登った**ことがあります**。（我爬过富士山）
- 納豆を食べた**ことがない**。（没吃过纳豆）

关键：**这是「经验」，不是「过去」**。它问的是「你这辈子有没有这个经历」。

## 02 たことがある vs た：经验 vs 事实

| 句子 | 意思 |
|---|---|
| 昨日、映画を見た | 昨天看了电影（事实） |
| 映画を見たことがある | 看过电影（有这经历） |

这就解释了为什么 `たことがある` 很少带具体时间：

- ✗ 昨日、映画を見たことがある
- ○ 昨日、映画を見た

## 03 ～たり～たりする：时而这样时而那样

```
动词た形 + り、动词た形 + り する
```

- 休みの日は、本を読ん**だり**、音楽を聞い**たり**します。（休息日看看书、听听音乐）
- 雨が降っ**たり**やん**だり**している。（雨时下时停）

三个要点：

1. 结尾必须是 **する**
2. 列举的是**代表性动作**，不穷尽
3. 前后时态由 `する` 决定

## 04 ～し～し：列举理由

```
普通形 + し、普通形 + し
```

- この店は安い**し**、おいしい**し**、よく来ます。（这家店又便宜又好吃，常来）
- 雨だ**し**、寒い**し**、出かけません。（又下雨又冷，不出门了）

「し」和「たり」的区别：

| 形式 | 列举什么 |
|---|---|
| たり | 动作（做的事） |
| し | 理由、性质（为什么/怎么样） |

## 05 ～という：叫做……

```
名词 + という + 名词
```

- 「源氏物語」**という**本を読みました。（读了叫《源氏物语》的书）
- 田中**という**人を知っていますか。（你认识叫田中的人吗）

「という」是日语里非常重要的「包装纸」——它把前面的内容变成一个整体，再去修饰后面的名词。

延伸用法：

- ～というのは（所谓……是）
- ～ということだ（也就是说）
- ～というより（与其说……不如说）

## 06 ～と思う：我认为

```
普通形 + と思う
```

- 明日は雨が降る**と思います**。（我觉得明天会下雨）
- これはいい**と思います**。（我觉得这个好）

⚠️ 注意：

1. 从句用**常体**（降る，不是降ります）
2. 第一人称的「思う」很自然；第三人称要 `と思っている`

| 主语 | 形式 |
|---|---|
| 我 | ～と思う |
| 他 | ～と思っている |

## 07 ～と言う / と聞く：说 / 听说

- 先生は「明日テストです」**と言いました**。（老师说「明天考试」）
- 明日テストがある**と聞きました**。（听说明天有考试）

引用有三种包装：

| 形式 | 用途 |
|---|---|
| と言う | 直接引用或转述 |
| と聞く | 听说 |
| と伝える | 转达 |

口语里的「って」是「と」的缩约：

- 明日テストだ**って**。（说是明天考试）

## 08 ～かどうか：是否

```
普通形 + かどうか
```

- 行く**かどうか**、まだ決めていません。（去不去还没决定）
- 本当か**どうか**、確かめます。（确认是不是真的）

⚠️ 这里不能用「か」单独：

- ✗ 行くか、まだ決めていない（不自然）
- ○ 行く**かどうか**、まだ決めていない

## 09 疑问词 + か：间接疑问

```
疑问词 + 普通形 + か
```

- どこに行く**か**、教えてください。（请告诉我你去哪）
- 何を食べたい**か**、決めてください。（请决定想吃什么）

这是「把疑问句装进另一个句子」的标准做法。对比：

| 直接 | 间接 |
|---|---|
| どこへ行きますか | どこへ行くか（教えてください） |
| 何ですか | 何か（わかりますか） |

## 10 ～のだ / ～んです：解释说明

这是日语口语里出现频率最高的句型之一，但教科书往往讲得含糊。

**基本功能：给前面的话加「背景说明」或「求解释」**。

- どうした**んですか**。（怎么了？——求解释）
- 頭が痛い**んです**。（因为我头疼——给理由）

三种典型场景：

| 场景 | 例 |
|---|---|
| 说明原因 | 遅れた**んです**。電車が止まって。 |
| 补充背景 | 実は、来月引っ越す**んです**。 |
| 请求解释 | なぜ来なかった**んですか**。 |

⚠️ 中文母语者常用错：**不要用它来陈述新事实**。`私は学生なんです` 只在「解释为什么我在这」这种语境下才自然。

## 本讲小结

N4 的从句结构可以归成三类：

| 类型 | 标志 | 例 |
|---|---|---|
| 名词化 | こと / の | 走る**こと**が好き |
| 引用 | と / という | 行く**と**思う |
| 疑问嵌入 | か / かどうか | 行く**か**知らない |

## 记忆卡片

> **たことがある** = 经验，不带具体时间
> **たり** 列动作；**し** 列理由
> **と思う** 我；**と思っている** 他
> **んです** 是解释，不是陈述
