日语有一个别的语言少见的习惯：**说一件事时，必须交代「我是怎么知道的」**。

- 亲眼看到的 → ようだ
- 听说的 → らしい / そうだ
- 只是猜测 → かもしれない / だろう

这不是语法装饰，是日语的**认识论**。用错，日本人会觉得你「说话太武断」。

## 01 ～だろう / でしょう：大概吧

```
普通形 + だろう（常体） / でしょう（敬体）
```

- 明日は雨が降る**でしょう**。（明天大概会下雨）
- 彼はもう着いた**だろう**。（他大概到了吧）

语气：**中等确信**，带一点「我想是这样，但不保证」。

降调时是推测，升调时是确认（`そうでしょう？`＝是吧？）。

## 02 ～かもしれない：也许（低确信）

```
普通形 + かもしれない
```

- 明日は雨が降る**かもしれません**。（明天也许会下雨）
- 田中さんは来ない**かもしれない**。（田中也许不来）

确信度是四姐妹里**最低**的。日本人非常爱用，因为它最安全——说错了也不算错。

口语缩约：`かも`。

## 03 ～ようだ：根据迹象判断

```
普通形 + ようだ（名词 + の + ようだ）
```

- 部屋が暗い。誰もいない**ようだ**。（房间很暗，好像没人）
- 風邪を引いた**ようです**。（好像感冒了）

「ようだ」的关键：**有观察依据**。不是凭空猜，而是「看到迹象→推断」。

所以它常和这些副词一起出现：

- どうやら（好像）
- どうも（总觉得）
- なんだか（总觉得）

## 04 ～みたいだ：ようだ 的口语版

```
普通形 + みたいだ（名词直接 + みたいだ）
```

- 雨が降っている**みたい**。（好像在下雨）
- 子どもの**みたい**だ。（像小孩一样）

接续差异（N3 常考）：

| | 名词接续 |
|---|---|
| ようだ | 学生**の**ようだ |
| みたいだ | 学生**みたいだ**（不加の） |

## 05 ～らしい（传闻）：听说

```
普通形 + らしい
```

- 田中さんは来月結婚する**らしい**。（听说田中下个月结婚）
- この店は有名**らしい**よ。（听说这家店很有名）

「らしい」的传闻，语感是**「我听到的消息是这样，但不是我亲眼所见」**。它比 `そうだ（传闻）` 更间接一点，也更常用于「客观传闻」。

## 06 ～らしい（典型）：很有……的样子

这是「らしい」的第二个身份，非常日语：

- 彼は男**らしい**。（他很有男子气概）
- 今日は春**らしい**天気だ。（今天是很有春天气息的天气）
- 自分**らしく**生きたい。（想活得像自己）

结构：`名词 + らしい` = 「符合那个名词应有的样子」。这是**评价**，不是推测。

## 07 ～そうだ（传闻）：据说

```
普通形 + そうだ（听说）
```

- 明日は雨が降る**そうです**。（听说明天下雨）
- 先生がおっしゃった**そうです**。（据说是老师说的）

⚠️ 传闻的「そうだ」**前面必须是普通形**，而且**不能是「～ない」以外的否定**错接：

- ○ 降るそうだ
- ✗ 降りますそうだ

## 08 ～そうだ（样态）：看起来

```
动词ます形去ます + そうだ
い形容词去い + そうだ
な形容词 + そうだ
```

- このケーキはおいし**そう**だ。（这蛋糕看起来好吃）
- 雨が降り**そう**だ。（看起来要下雨了）
- 彼は元気**そう**だ。（他看起来精神很好）

⚠️ 两个特殊：

- `いい` → **よさそう**（不是「いそう」）
- `ない` → **なさそう**

⚠️ 而且样态的「そうだ」**不能修饰名词**，那要用 `そうな`：

- おいし**そうな**ケーキ（看起来好吃的蛋糕）

## 09 确信度阶梯

![推量四姐妹确信度](IMG_SUIRYO)

从高到低：

| 确信度 | 形式 | 依据 |
|---|---|---|
| 90% | はずだ | 逻辑必然 |
| 80% | にちがいない | 强烈推断 |
| 70% | だろう / でしょう | 综合判断 |
| 60% | ようだ / みたいだ | 观察迹象 |
| 50% | らしい / そうだ（传闻） | 二手信息 |
| 30% | かもしれない | 可能性 |

注意：**传闻类（らしい・そうだ）的确信度不取决于你多确信，而取决于信息来源的可靠度**。这是它和「だろう」的本质区别。

## 10 副词搭配：让推量更精准

日语推量句常配副词，搭配错了会不自然：

| 副词 | 常配 | 意思 |
|---|---|---|
| たぶん | だろう / でしょう | 大概 |
| おそらく | だろう / にちがいない | 恐怕（书面） |
| どうやら | ようだ / らしい | 好像 |
| もしかすると | かもしれない | 说不定 |
| ひょっとしたら | かもしれない | 万一 |
| 見たところ | ようだ | 从外观来看 |

例：

- **どうやら**雨が降った**ようだ**。（好像下过雨）
- **もしかすると**間に合わない**かもしれない**。（说不定赶不上）

## 本讲小结

选哪个，问自己两个问题：

1. **我是怎么知道的？**（看到 / 听说 / 纯粹猜）
2. **我有多确信？**

答案自然就出来了。

## 记忆卡片

> **ようだ** 观察推断；**らしい** 听说 / 有……的样子
> **そうだ** 传闻接普通形，样态接ます形词干
> **いい→よさそう**，**ない→なさそう**
> 名词接续：学生**の**ようだ / 学生**みたいだ**
