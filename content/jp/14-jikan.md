中文说「一边吃饭一边看手机」，日语能选 `ながら`；说「趁着年轻」，选 `うちに`；说「每次去都下雨」，选 `たびに`。

这些形式在中文里都像「的时候」，但日语把它们按**时间关系**切得很细。这一讲做精度校准。

## 01 ～ながら：两个动作同时

```
动词ます形去ます + ながら
```

- 音楽を聞き**ながら**勉強します。（边听音乐边学习）

三条硬规则（N4 讲过，N3 再确认）：

1. **同一主语**
2. **主句是主要动作**（ながら 部分是附带）
3. **不能是瞬间动词**

⚠️ `ながら` 还有一个完全不同的用法：**逆接**（残念ながら、知っていながら）。这是 N3 的新内容：

- 彼はお金があり**ながら**、幸せではない。（他虽然有钱，却不幸福）

## 02 ～つつ：ながら 的书面版

```
动词ます形去ます + つつ
```

- 将来のことを考え**つつ**、今を生きる。（一边考虑将来，一边活在当下）
- 酒を飲み**つつ**語り合った。（一边喝酒一边聊）

`つつ` 和 `ながら` 的差别：

| | 语体 | 感觉 |
|---|---|---|
| ながら | 口语 | 日常 |
| つつ | 书面 | 文章、演讲、歌词 |

另外 `つつ` 也有逆接：`悪いと知りつつ、やめられない`（明知不好却戒不掉）。

## 03 ～間 / ～間に：整段时间 vs 期间某点

这是 N3 最常考的一组对比：

| 形式 | 意思 | 例 |
|---|---|---|
| ～間 | 整个期间都在做 | 夏休みの**間**、ずっと旅行していた |
| ～間に | 期间内发生了某事 | 夏休みの**間に**、一度旅行した |

一句话：**「間」是持续，「間に」是点**。

同样的对比：

- 私が寝ている**間**、雨が降り続いた。（我睡着的整段时间，雨一直下）
- 私が寝ている**間に**、雨が降った。（我睡着的时候，下了雨）

## 04 ～うちに：趁着

```
动词辞书形/ている形 + うちに
い形容词 + うちに
な形容词 + な + うちに
名词 + の + うちに
```

两种用法：

**① 趁着（状态还在）**
- 若い**うちに**、たくさん旅行したい。（趁着年轻多旅行）
- 熱い**うちに**食べてください。（趁热吃）

**② 不知不觉发生变化**
- 歩いている**うちに**、日が暮れた。（走着走着天就黑了）

第二用法常和「不知不觉」的语感绑定，中文对应「……着……着就」。

## 05 ～たびに：每次

```
动词辞书形 + たびに
名词 + の + たびに
```

- この写真を見る**たびに**、学生時代を思い出す。（每次看这张照片就想起学生时代）
- 会う**たびに**、彼は痩せていく。（每次见他都瘦一点）

和 `～たら` 的区别：たびに 是**反复**，必须多次发生。

## 06 ～とたん（に）：刚一……就

```
动词た形 + とたん（に）
```

- 家を出た**とたん**、雨が降り出した。（刚出门就下雨了）
- 名前を呼んだ**とたん**、彼は振り向いた。（刚一叫名字他就回头了）

三个特点：

1. **必须是た形**
2. 后句是**意外的事**，不能是自己的意志行为
3. ✗ 家を出たとたん、コンビニに行った

## 07 ～最中に：正在……的时候

```
动词ている形 + 最中に
名词 + の + 最中に
```

- 会議の**最中に**、携帯が鳴った。（会议进行中手机响了）
- 食事をしている**最中に**、地震があった。

语感：**正处于高峰期，被打断**。比「間に」多一层「正忙着」的味道。

## 08 ～次第：一……就（马上做）

```
动词ます形去ます + 次第
```

- 着き**次第**、連絡します。（一到就联系你）
- 決まり**次第**、お知らせします。（一决定就通知您）

⚠️ 商务日语高频。特点是：**后句是说话人主动要做的事**（意志行为）。

对比 `とたん`：とたん 后半句不能是意志，次第 后半句**必须是意志**。正好相反。

## 09 ～かと思うと / ～かと思ったら：刚以为……就

```
动词た形 + かと思うと / かと思ったら
```

- 雨が降った**かと思うと**、すぐやんだ。（刚以为下雨了，马上就停了）
- 泣いていた**かと思ったら**、もう笑っている。（刚以为在哭，已经在笑了）

语感：**两个相反的情况快速交替**，常带一点「让人措手不及」。

## 10 精度对照总表

| 形式 | 时间关系 | 后句限制 |
|---|---|---|
| ながら | 同时（主从） | 同一主语 |
| つつ | 同时（书面） | 同一主语 |
| 間 | 整个期间 | 持续 |
| 間に | 期间内某点 | 一次性 |
| うちに | 状态未变之前 | 意志或变化 |
| たびに | 每次反复 | 反复 |
| とたん | 瞬间后 | 意外、非意志 |
| 最中に | 正进行时 | 打断 |
| 次第 | 之后立刻 | 意志行为 |
| かと思うと | 刚……就反转 | 意外 |

---

## 本讲小结

判断顺序：

1. 两个动作**同时**？→ ながら / つつ
2. 强调**整段时间**还是**期间某点**？→ 間 / 間に
3. 强调**趁状态还在**？→ うちに
4. 强调**瞬间之后**？→ とたん（意外）/ 次第（意志）

## 记忆卡片

> **間** 持续，**間に** 某点
> **とたん** 后句不能是意志；**次第** 后句必须是意志
> **うちに** 有两个意思：趁着 / 不知不觉
> **たびに** 必须反复发生
