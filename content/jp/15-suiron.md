日语的「判断」比中文讲究得多。中文说「应该」，可以指推测（他应该到了），也可以指义务（你应该去）。日语把这两件事彻底分开：

- 推测 → はずだ
- 义务 → べきだ

这一讲把四条逻辑线一次理清。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～ようになる | 能力或习惯的变化 |
| 02 | ～ようにする | 努力做到 |
| 03 | ～ことになる | 被决定、结果如此 |
| 04 | ～ことにする | 我自己决定 |
| 05 | ～わけだ | 自然就是这么回事 |
| 06 | ～わけではない | 并不是说 |
| 07 | ～はずだ | 逻辑上必然 |
| 08 | ～はずがない | 不可能 |
| 09 | ～べきだ | 道义上应该 |
| 10 | ～べきではない / べきだった | 不该 / 当初该 |

## 01 ～ようになる：能力或习惯的变化

```
动词辞书形/ない形 + ようになる
```

- 日本語が話せる**ようになりました**。（变得会说日语了）
- 毎朝走る**ようになった**。（养成了每天早跑的习惯）
- お酒を飲ま**なくなった**。（不喝酒了）

两种典型场景：

| 场景 | 例 |
|---|---|
| 能力变化 | 泳げるようになった |
| 习惯变化 | タバコを吸わなくなった |

⚠️ 注意：`ようになる` 前面**常用可能形**，因为「能力变化」是最常见的用法。

## 02 ～ようにする：努力做到

```
动词辞书形/ない形 + ようにする
```

- 毎日野菜を食べる**ようにしています**。（我尽量每天吃蔬菜）
- 遅刻しない**ようにしてください**。（请尽量不要迟到）

对比记忆：

| 形式 | 谁在变 |
|---|---|
| ようになる | **状态**自然变化 |
| ようにする | **人**有意识努力 |

一句话：**「なる」是变，「する」是做。**

## 03 ～ことになる：被决定 / 结果如此

```
动词辞书形/ない形 + ことになる
```

两种用法：

**① 组织决定（自己不参与）**
- 来月、大阪に転勤する**ことになりました**。（下个月被调到大阪）

**② 逻辑推导出的结果**
- 一時間かかる**ことになる**。（算下来要一小时）
- つまり、彼は来ない**ことになる**。（也就是说，他不会来了）

## 04 ～ことにする：我自己决定

- 今日からタバコをやめる**ことにしました**。（我决定从今天起戒烟）

和 03 的区别只有一条：**谁做决定**。

| 形式 | 决定者 |
|---|---|
| ことにする | 我 |
| ことになる | 别人 / 组织 / 逻辑 |

## 05 ～わけだ：自然就是这么回事

```
普通形 + わけだ
```

- 10年日本に住んでいた。日本語が上手な**わけだ**。（在日本住了十年，难怪日语好）
- つまり、彼はもう帰った**わけだ**。（也就是说，他已经回去了）

「わけだ」的语感：**根据前面的事实，得出「理所当然」的结论**。中文最贴切的是「难怪」「也就是说」。

## 06 ～わけではない：并不是说

- 日本料理が嫌いな**わけではない**。（并不是讨厌日本料理）
- 全員が賛成した**わけではない**。（并不是全体赞成）

这是**部分否定**，非常重要：

| 形式 | 意思 |
|---|---|
| 全部否定 | 誰も賛成しなかった |
| 部分否定 | 賛成しないわけではない（不是不赞成） |

日语里 `わけではない` 常用来**软化否定**，让话不那么绝对。

## 07 ～はずだ：逻辑上必然

```
普通形 + はずだ
```

- 彼はもう着いている**はずだ**。（他应该已经到了）
- この店は日曜日だから、混んでいる**はずだ**。（周日，应该很挤）

「はずだ」的依据是**逻辑或已知事实**，不是感觉。这是它和「だろう」的核心区别：

| 形式 | 依据 |
|---|---|
| だろう | 综合印象、直觉 |
| はずだ | 客观推理（A 成立，B 必然） |

## 08 ～はずがない：不可能

- そんな**はずがない**。（不可能有那种事）
- 彼が嘘をつく**はずがない**。（他不可能说谎）

语气比 `ない` 强得多，接近「绝对不可能」。

还有一个近义：`わけがない`，意思基本相同，但更口语、更情绪化。

## 09 ～べきだ：道义上应该

```
动词辞书形 + べきだ（する→すべきだ / するべきだ）
```

- 学生はもっと勉強する**べきだ**。（学生应该更用功）
- 約束は守る**べきです**。（应该守约）

「べきだ」的语感是**规范、道义、社会责任**，比「ほうがいい」强得多：

| 形式 | 强度 |
|---|---|
| ～たほうがいい | 建议（你可以不听） |
| ～べきだ | 应该（不听就不对） |

⚠️ `べき` 不能用于自己对自己的谦逊表达（`私は行くべきだ` 会有「我在责备自己」的味道）。

## 10 ～べきではない / ～べきだった：不该 / 当初该

| 形式 | 意思 |
|---|---|
| べきではない | 不应该（现在·一般） |
| べきだった | 当初应该（后悔） |
| べきではなかった | 当初不该（后悔） |

- 人の悪口を言う**べきではない**。（不该说人坏话）
- もっと早く病院に行く**べきだった**。（当初该早点去医院）

`べきだった` 是日语表达**后悔**最标准的形式之一。

## 本讲小结

| 形式 | 依据 | 中文 |
|---|---|---|
| ようになる | 状态变化 | 变得 |
| ようにする | 人的努力 | 尽量 |
| ことになる | 被决定 / 推导 | 定了 / 也就是说 |
| ことにする | 自己决定 | 我决定 |
| わけだ | 自然结论 | 难怪 / 也就是说 |
| わけではない | 部分否定 | 并不是 |
| はずだ | 逻辑必然 | 应该（推测） |
| べきだ | 道义规范 | 应该（义务） |

## 记忆卡片

> **なる是变，する是做**
> **わけだ** = 难怪；**はずだ** = 按理说
> **べきだ** 是义务，不是推测
> **べきだった** 是最标准的「后悔」
