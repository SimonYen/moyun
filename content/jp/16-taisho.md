「对」是日语翻译里最危险的一个字。因为它背后的日语形式，每一个都有自己的「镜头角度」：

- 对某个话题 → について
- 对某个对象的态度 → に対して
- 从某人的立场看 → にとって
- 因人而异 → によって

用错不会让人听不懂，但会让人觉得你**没抓住那个角度**。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～について | 关于（话题） |

| 03 | ～にとって | 对……来说（立场） |
| 04 | ～によって | 四个身份 |
| 05 | ～として | 作为（身份） |
| 06 | ～に関して | 关于（更正式） |
| 07 | ～に応じて | 根据（相应变化） |
| 08 | ～に比べて | 与……相比 |
| 09 | ～に加えて | 加上 |
| 10 | ～をめぐって | 围绕（争议） |

## 01 ～について：关于（话题）

```
名词 + について
```

- 日本の歴史**について**調べています。（正在查关于日本历史的东西）
- この問題**について**、どう思いますか。（关于这个问题你怎么想）

`について` 是最中性的「关于」，后面常接**调查、研究、说话、思考**这类动词。

## 02 ～に対して：对（态度、对比）

两种用法：

**① 对某个对象的态度**
- 先生**に対して**失礼なことを言った。（对老师说了失礼的话）
- 客**に対して**丁寧に話す。（对客人礼貌说话）

**② 对比（「而」）**
- 兄は活発な**のに対して**、弟はおとなしい。（哥哥活泼，而弟弟文静）

第二种用法在写作里非常常用，用来做**对照**。

## 03 ～にとって：对……来说（立场）

```
名词 + にとって
```

- 私**にとって**、家族が一番大切です。（对我来说家人最重要）
- 子ども**にとって**、遊びは学びだ。（对孩子来说，玩就是学）

⚠️ 关键：`にとって` 后面接的是**评价**（重要、难、必要、ありがたい），不接具体动作。

- ○ 私にとって難しい
- ✗ 私にとって本を読む

## 04 ～によって：四个身份

这是 N3 最容易混的一个，因为它有四个完全不同的意思：

| # | 意思 | 例 |
|---|---|---|
| 1 | 由（被动句的动作主体） | この絵はピカソ**によって**描かれた |
| 2 | 由于（原因） | 台風**によって**電車が止まった |
| 3 | 根据、通过（手段） | 調査**によって**わかった |
| 4 | 因……而异 | 人**によって**考え方が違う |

第 4 个最值得注意：`～によって違う`（因人而异）是高频搭配。

## 05 ～として：作为（身份）

```
名词 + として
```

- 留学生**として**日本に来ました。（作为留学生来日本）
- 彼は医者**として**働いている。（他作为医生工作）

否定形：`～としては`（作为……来说）、`～としても`（即使作为……也）。

## 06 ～に関して：关于（更正式）

`について` 的书面升级版：

- この件**に関して**、ご説明します。（关于此事，我来说明）
- 環境問題**に関して**の調査。（关于环境问题的调查）

差别只在于语体：

| | 语体 |
|---|---|
| について | 一般 |
| に関して | 正式、书面 |

## 07 ～に応じて：根据（相应变化）

- 収入**に応じて**税金が変わる。（税金随收入变化）
- お客様のご要望**に応じて**対応します。（根据客户需求应对）

`に応じて` 的核心是**变化对应**：A 变了，B 跟着变。

对比 `によって`：

- `人によって違う` = 因人而异（陈述差异）
- `収入に応じて変わる` = 随收入变化（强调对应关系）

## 08 ～に比べて：与……相比

- 去年**に比べて**、今年は暑い。（比去年热）
- 東京**に比べて**、大阪は安い。（相比东京，大阪便宜）

常和这些副词搭配：`ずっと`（得多）、`少し`（一点）、`かなり`（相当）。

## 09 ～に加えて：加上

- 雨**に加えて**、風も強くなった。（除了雨，风也变强了）
- 経験**に加えて**、資格も持っている。（除了经验，还有资格）

书面语里也作 `～に加え`，更简洁。

## 10 ～をめぐって：围绕（争议）

```
名词 + をめぐって
```

- その計画**をめぐって**、議論が続いている。（围绕那个计划，争论在持续）
- 遺産**をめぐって**、兄弟が争った。（围绕遗产，兄弟争执）

`をめぐって` 只用于**有争议、有多种立场**的事情。这是它和 `について` 的分界：

- `について` 中性（关于）
- `をめぐって` 有对立（围绕……争论）

## 本讲小结

按「镜头角度」分类：

| 角度 | 形式 |
|---|---|
| 话题 | について / に関して |
| 态度 | に対して |
| 立场 | にとって |
| 身份 | として |
| 原因/手段/主体/差异 | によって |
| 对应变化 | に応じて |
| 比较 | に比べて |
| 附加 | に加えて |
| 争议 | をめぐって |

## 记忆卡片

> **にとって** 后接评价，不接动作
> **によって** 有四个意思，最常考「因人而异」
> **として** 是身份，不是立场
> **をめぐって** 必须带争议
