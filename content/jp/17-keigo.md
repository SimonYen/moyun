大多数人对敬语的恐惧来自「特殊动词表」——いらっしゃる、召し上がる、伺う、申し上げる……二十几个词，背了忘，忘了背。

但敬语的**底层规则只有一条**：

> **抬高对方的人和行为（尊敬语），压低自己和自己人的行为（谦让语）。**

所有特殊动词都是这条规则的产物。先理解规则，表就好背了。

## 01 三类敬语：先分清功能

| 类型 | 作用 | 谁做动作 |
|---|---|---|
| 尊敬语（尊敬語） | 抬高对方 | 对方 |
| 谦让语（謙譲語） | 压低自己 | 自己 |
| 郑重语（丁寧語） | 让语气礼貌 | — |

`です・ます` 属于**郑重语**，它不抬高任何人，只是让话不粗鲁。所以：

- `社長が来ます`（郑重，但没敬对方）
- `社長がいらっしゃいます`（尊敬，抬高了社长）

## 02 尊敬语：れる / られる

最简单的敬语：把动词变成被动形。

- 社長が来**られます**。（社长来）
- 先生が話**されます**。（老师说）

这是「省事版敬语」，日常对上级用它完全够用。缺点是**一段动词容易歧义**（食べられる = 能吃/被吃/敬语）。

## 03 尊敬语：お / ご～になる

标准形式，最安全：

```
和语词：お + ます形去ます + になる
汉语词：ご + 名词 + になる
```

- 社長はもうお帰り**になりました**。（社长已经回去了）
- 先生はご覧**になりましたか**。（老师您看了吗）

⚠️ 只用于**对方的动作**。

## 04 谦让语：お / ご～する

```
和语词：お + ます形去ます + する
汉语词：ご + 名词 + する
```

- お荷物をお持ち**します**。（我来拿行李）
- ご案内**します**。（我带您去）

⚠️ 只用于**自己的动作**，而且动作的受益者是对方。

## 05 谦让语三兄弟：いたす・まいる・もうす

| 普通 | 谦让 | 用法 |
|---|---|---|
| する | いたす | ご連絡いたします |
| 行く・来る | まいる | 明日伺います / まいります |
| 言う | もうす | 田中と申します |

还有一个：`存じる`（思う・知る 的谦让）

- その件は**存じて**おります。（那件事我知道）

## 06 郑重语：ございます

`あります` 的郑重形式：

- こちらに**ございます**。（在这边）
- お時間は**ございますか**。（您有时间吗）

还有 `でございます`（です 的郑重）：

- 田中**でございます**。（我是田中）

⚠️ 郑重语可以对外人用（因为它不抬人），所以在服务业里几乎每句都有。

## 08 内与外原则：敬语最重要的潜规则

日语敬语不只看「上下」，还看「内外」：

> **对外人说话时，即使是自己的上司，也要用谦让语。**

例：对客户提到自己的部长：

- ✗ うちの部長が**いらっしゃいます**
- ○ うちの部長が**おります**

因为「对外人来说，部长是『我方』的人」，所以要压低。

这条规则解释了很多「看起来矛盾」的敬语：

| 场景 | 对自己的上司 | 对客户提自己的上司 |
|---|---|---|
| 去 | いらっしゃる | まいる |
| 说 | おっしゃる | 申す |
| 在 | いらっしゃる | おる |

## 09 二重敬语：越堆越错

敬语不能叠加。以下是典型错误：

| ✗ 错误 | 原因 | ○ 正确 |
|---|---|---|
| おっしゃられました | おっしゃる 已是尊敬 + られる | おっしゃいました |
| ご覧になられました | ご覧になる + られる | ご覧になりました |
| お召し上がりになられました | 三层 | 召し上がりました |
| お伺いいたします | 伺う + いたす | 伺います |

判断方法：**一句话里同一个「抬高」只能出现一次。**

## 10 商务邮件模板：直接能用

**开头**
```
株式会社○○ 田中様
いつもお世話になっております。△△の佐藤でございます。
```

**正文**
```
このたびは、貴重なお時間をいただき、誠にありがとうございました。
ご依頼の件につきまして、下記のとおりご報告申し上げます。
```

**结尾**
```
ご不明な点がございましたら、お気軽にお問い合わせください。
何卒よろしくお願い申し上げます。

△△株式会社 佐藤一郎
```

三个高频短语拆解：

| 短语 | 拆解 |
|---|---|
| お世話になっております | お世話になる（谦让）+ ています |
| ご報告申し上げます | ご + 報告 + 申し上げる（最谦） |
| よろしくお願い申し上げます | 願う + 申し上げる |

## 本讲小结

敬语的判断顺序：

1. **动作是谁做的？** 对方 → 尊敬语；自己 → 谦让语
2. **听者是谁？** 外人 → 我方一律谦让
3. **会不会重复抬高？** 会 → 删掉一层

## 记忆卡片

> **三类**：尊敬（抬人）・谦让（压己）・郑重（礼貌）
> **れる/られる** 是最省事的尊敬语
> **对外人提自己人** → 一律谦让
> **おっしゃられました** 是经典错误
