日语的转折分两个层次：

- **逆接**（けれど、が）——普通的「但是」
- **让步**（ものの、にもかかわらず）——「虽然承认 A，但 B」

N2 的重点是让步。它的核心是：**先承认对方说得对，再给出反例**。这个结构在日语里极其常见，因为它是「礼貌地反对」的标准姿势。

## 01 ～ものの：虽然……但是（书面）

```
普通形 + ものの
名词 + である + ものの
な形容词 + な + ものの
```

- 免許は取った**ものの**、まだ運転していない。（驾照是考了，但还没开过）
- 値段は安い**ものの**、品質が心配だ。（价格是便宜，但担心质量）

核心语感：**「A 确实成立，但实际情况不如预期」**。它带一点**无奈、未完成**的味道。

## 02 ～ながらも：虽然……却

```
动词ます形去ます + ながらも
い形容词 + ながらも
な形容词 + ながらも / でありながらも
名词 + ながらも
```

- 狭い**ながらも**、快適な部屋だ。（虽然小，但是个舒适的房间）
- 彼は若い**ながらも**、責任感が強い。（他虽然年轻，责任感很强）

`ながらも` 常带一点**正面评价**：虽然条件不足，但结果不错。

## 03 ～とはいえ：虽说如此

```
普通形 + とはいえ
名词 + とはいえ
```

- 春**とはいえ**、まだ寒い。（虽说是春天，还是冷）
- プロ**とはいえ**、ミスはある。（虽说是专业，也会出错）

核心语感：**「名义上 A 成立，但实际上要打折」**。中文最贴切：「话虽如此」「虽说是……」。

## 04 ～にもかかわらず：尽管（强烈）

```
普通形 + にもかかわらず
名词 + にもかかわらず
```

- 雨**にもかかわらず**、多くの人が集まった。（尽管下雨，还是很多人聚集）
- 何度も注意した**にもかかわらず**、彼はやめなかった。（尽管提醒了很多次，他还是没停）

这是**最强的让步**，常带**惊讶、不满、评价**。语体正式，新闻、评论里常见。

⚠️ 不能用于自己的谦逊表达，也不能用在轻松语境。

## 05 ～つつ（逆接）：明知却

```
动词ます形去ます + つつ（も）
```

- 悪いと知り**つつ**、ついやってしまう。（明知不好还是做了）
- 体に悪いと知り**つつも**、タバコがやめられない。

和 `ながらも` 的区别：`つつ` 更书面，且常指**同一主语内心的矛盾**（明知/却）。

## 06 ～といっても：虽说……但也就

```
普通形 + といっても
名词 + といっても
```

- 料理ができる**といっても**、卵焼きだけだ。（虽说会做饭，也就会煎蛋）
- 日本**といっても**、行ったのは東京だけだ。（虽说日本，只去过东京）

核心：**先承认一个大说法，再缩小它的实际范围**。中文：「说是……其实也就」。

## 07 ～からといって：不能因为……就

```
普通形 + からといって（～ない）
```

- 日本人だ**からといって**、漢字が全部読めるわけではない。（不能因为是日本人，就认为汉字全认得）
- 安い**からといって**、たくさん買うのはよくない。

这个句型**几乎总是否定结尾**，用来**否定「简单因果」**。N2 高频。

## 08 ～わりに（は）：相对而言

```
普通形 + わりに（は）
名词 + の + わりに
```

- 値段の**わりに**、おいしい。（相对价格来说很好吃）
- 彼は若い**わりに**、落ち着いている。（他相对年龄来说很沉稳）

核心：**「按 A 的标准衡量，B 出乎意料」**。可以正面也可以负面。

## 09 ～くせに：明明……却（责难）

```
普通形 + くせに
名词 + の + くせに
```

- 知っている**くせに**、教えてくれない。（明明知道却不告诉我）
- 男の**くせに**、泣くなよ。

⚠️ 这个句型**带强烈责难**，只能用于**别人**，不能用于自己，也不能对上级用。

## 10 四者语感对比

| 形式 | 情绪 | 语体 | 用法 |
|---|---|---|---|
| ものの | 无奈、未达预期 | 书面 | 客观陈述 |
| ながらも | 意外但正面 | 书面 | 评价 |
| とはいえ | 打折、保留 | 书面 | 修正说法 |
| にもかかわらず | 惊讶、不满 | 正式 | 强烈对比 |
| くせに | 责难、轻蔑 | 口语 | 只能对人 |
| わりに | 出乎意料 | 口语/书面 | 比例评价 |
| からといって | 否定推论 | 书面 | 几乎必带否定 |

---

## 本讲小结

选哪个，看**情绪**：

- 只是客观承认 → ものの
- 想表达意外的好 → ながらも
- 想修正对方的印象 → とはいえ
- 想表达惊讶或不满 → にもかかわらず
- 想骂人 → くせに

## 记忆卡片

> **ものの** = 虽然（书面、无奈）
> **にもかかわらず** 是最强让步
> **からといって** 后面几乎都是否定
> **くせに** 只能对人，且是骂人的
