限定类句型在 N2 考试里出现频率极高，因为它们**形式相似、意思相反**，特别适合出题。

这一讲按「范围的宽窄」排一遍，从「只此一个」到「全部不管」。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～に限り | 只限于（特别措施） |
| 02 | ～に限って | 偏偏 / 只有……才 |
| 03 | ～に限らず | 不只 |
| 04 | ～を問わず | 不问（年龄、性别） |
| 05 | ～をおいて | 除了……没有 |
| 06 | ～ならでは | 只有……才有 |
| 07 | ～だけあって | 不愧是 |
| 08 | ～ばかりか | 不仅……而且 |
| 09 | ～どころか | 岂止……反而 |
| 10 | ～はもとより | 自不必说 |

## 01 ～に限り：只限于（特别措施）

```
名词 + に限り
```

- 本日に**限り**、全品半額。（仅限今天，全场半价）
- 会員**に限り**、入場無料。（仅限会员免费入场）

核心：**设定一个例外性的范围**。它常出现在**告示、通知**里，带着「平时不是这样」的味道。

## 02 ～に限って：偏偏 / 只有……才

这是 `に限って` 的两个完全不同的意思：

**① 偏偏（不幸的巧合）**
- 急いでいる時に**限って**、電車が遅れる。（偏偏赶时间的时候电车晚点）
- 伞を持っていない日に**限って**、雨が降る。（偏偏没带伞那天下雨）

**② 只有……才（信任）**
- うちの子に**限って**、そんなことはしない。（我们家孩子绝不会做那种事）

第二种常带**护短、信任**的情绪，是日语很地道的一种表达。

## 03 ～に限らず：不只

```
名词 + に限らず
```

- 若者**に限らず**、年配者もスマホを使う。（不只年轻人，年长者也用智能手机）
- 日本**に限らず**、少子化は世界的な問題だ。

和 `だけでなく` 同义，但更书面。

## 04 ～を問わず：不问（条件）

```
名词 + を問わず
```

- 年齢・性別**を問わず**、誰でも参加できます。（不问年龄性别，谁都能参加）
- 昼夜**を問わず**、電話してください。（不管昼夜都可以打）

常搭配：`年齢`、`性別`、`国籍`、`経験`、`昼夜`、`国内外`。

变体：`は問わず`、`を問うことなく`（更文学）。

## 05 ～をおいて：除了……没有

```
名词 + をおいて（～ない）
```

- この仕事を任せられるのは、彼**をおいて**いない。（能托付这工作的人，除了他没有）
- 京都**をおいて**、こんなに美しい町はない。

⚠️ 句式固定：`A をおいて B ない`。后面几乎总是否定。

## 06 ～ならでは：只有……才有

```
名词 + ならでは（の + 名词）
```

- 京都**ならでは**の風景。（只有京都才有的风景）
- 彼**ならでは**のアイデアだ。（只有他才想得出的点子）

核心：**某个对象独有的特质**，通常是**正面评价**。

## 07 ～だけあって：不愧是

```
普通形 + だけあって
名词 + だけあって
```

- さすがプロ**だけあって**、仕事が早い。（不愧是专业，干活快）
- 十年住んでいる**だけあって**、日本語が上手だ。（不愧住了十年，日语很好）

`だけあって` 常和 `さすが` 连用，表示**「果然符合其身份」**。

反面版：`だけに`（正因为……所以更）。

## 08 ～ばかりか：不仅……而且

```
普通形 + ばかりか
名词 + ばかりか
```

- 彼は英語**ばかりか**、中国語も話せる。（他不仅会英语，还会中文）
- 雨が降っている**ばかりか**、風も強い。

核心：**后项比前项更进一步**。常和 `も`、`まで` 呼应。

## 09 ～どころか：岂止……反而

这是 N2 最容易错的一个，因为它有**两个相反的方向**：

**① 岂止（程度更高）**
- 日本語**どころか**、英語も話せない。（别说日语了，连英语都不会）

**② 反而（完全相反）**
- 薬を飲んだ**どころか**、具合が悪くなった。（不但没吃药，反而更难受了 / 吃了药反而更糟）

判断方法：看后项是**递进**还是**反转**。多数情况是指「别说 A，连更低的 B 都不行」。

## 10 ～はもとより：自不必说

```
名词 + はもとより
```

- 日本語**はもとより**、英語もできる。（日语自不必说，英语也会）
- 国内**はもとより**、海外でも人気がある。

和 `ばかりか` 的区别：`はもとより` 的**前项是「理所当然的」**，所以语气更「不必提」。

## 本讲小结

按范围排：

| 范围 | 形式 | 中文 |
|---|---|---|
| 只此一个 | をおいて | 除了……没有 |
| 只限 | に限り | 仅限 |
| 偏偏 | に限って | 偏偏 |
| 正向递进 | ばかりか / はもとより | 不仅 |
| 反向递进 | どころか | 岂止 |
| 向外扩展 | に限らず | 不只 |
| 全部覆盖 | を問わず | 不管 |
| 独有 | ならでは | 只有……才有 |
| 名副其实 | だけあって | 不愧是 |

## 记忆卡片

> **に限って** 有「偏偏」和「只有……才」两义
> **をおいて** 后面一定是否定
> **どころか** 是「岂止」，方向可能反转
> **はもとより** 前项是理所当然的
