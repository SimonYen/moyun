N1 阅读的难点从来不是单词，而是**句子结构**。一段话里塞了三个书面句型，每个都改变一次语气，你读到最后已经忘了主语是谁。

这一讲拆十个最高频的「承重墙」。认熟了，长句会自动分段。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～つつある | 正在（缓慢变化） |
| 02 | ～べく | 为了（书面） |
| 03 | ～んばかりに | 简直像要……一样 |
| 04 | ～がたい | 难以（心理上） |
| 05 | ～かねる | 难以（委婉拒绝） |
| 06 | ～かねない | 有可能（负面） |
| 07 | ～を余儀なくされる | 被迫 |
| 08 | ～ずにはいられない | 忍不住 |
| 09 | ～ないまでも | 即使不到……至少 |
| 10 | ～いかんにかかわらず | 无论……如何 |

## 01 ～つつある：正在（缓慢变化）

```
动词ます形去ます + つつある
```

- 日本の人口は減少し**つつある**。（日本人口正在减少）
- 社会は変わり**つつある**。（社会正在变化）

和 `ている` 的区别：`つつある` 强调**不可逆的、缓慢的、宏观的变化**，且是**书面语**。它常用于社会、经济、环境这类大话题。

⚠️ 不能用于瞬间动作或一次性事件。

## 02 ～べく：为了（书面）

```
动词辞书形 + べく（する → すべく）
```

- 真実を明らかにす**べく**、調査を始めた。（为了查明真相，开始了调查）
- 合格す**べく**、毎日勉強した。

`べく` = `ために` 的书面版。它常出现在**决心、目的、行动**的语境里，带一点「郑重其事」。

变体：`べくして` = 「必然地」：

- 起こる**べくして**起こった事件。（注定要发生的事件）

## 03 ～んばかりに：简直像要……一样

```
动词ない形去ない + んばかりに（する→せんばかりに）
```

- 彼は泣か**んばかり**の顔をしていた。（他一副快要哭出来的样子）
- 今にも雨が降ら**んばかり**の空だ。（天像是马上要下雨）

核心：**「虽然没有真的发生，但已经达到那个程度」**。非常文学化，小说里常见。

## 04 ～がたい：难以（心理上）

```
动词ます形去ます + がたい
```

- 信じ**がたい**話だ。（难以相信的话）
- この景色は言葉に表し**がたい**。（这景色难以用语言表达）

⚠️ `がたい` 是**心理上的难以**，不是能力上的不能：

| 形式 | 类型 |
|---|---|
| がたい | 心理上难以（信じがたい、理解しがたい） |
| にくい | 客观上难做（食べにくい、書きにくい） |
| づらい | 做起来难受（言いづらい、聞きづらい） |

固定搭配：`信じがたい`、`理解しがたい`、`許しがたい`、`動かしがたい`、`ありがたい`（原义「难得」）。

## 05 ～かねる：难以（委婉拒绝）

```
动词ます形去ます + かねる
```

- その件については、お答えし**かねます**。（那件事我难以回答）
- ご要望には応じ**かねます**。（难以满足您的要求）

这是**商务日语里最礼貌的拒绝**。它不直接说「不行」，而是说「我很难做到」。

⚠️ 注意：主语通常是**说话人自己**，表示「我做不到」，而不是对方做不到。

## 06 ～かねない：有可能（负面）

```
动词ます形去ます + かねない
```

- このままでは、事故になり**かねない**。（这样下去可能出事故）
- 彼ならやり**かねない**。（他说不定真会干）

⚠️ `かねる`（难以）和 `かねない`（可能）**意思完全相反**，只差一个「ない」。这是 N1 经典陷阱。

| 形式 | 意思 |
|---|---|
| しかねる | 难以做到（否定） |
| しかねない | 有可能做出（负面） |

## 07 ～を余儀なくされる：被迫

```
名词 + を余儀なくされる
名词 + を余儀なくさせる（使……被迫）
```

- 台風で、住民は避難**を余儀なくされた**。（因台风，居民被迫避难）
- 疫情は私たちの生活様式の変更**を余儀なくさせた**。

注意两个方向：

| 形式 | 谁被迫 |
|---|---|
| を余儀なくされる | 主语被迫 |
| を余儀なくさせる | 主语让别人被迫 |

## 08 ～ずにはいられない：忍不住

```
动词ない形去ない + ずにはいられない（する→せずにはいられない）
```

- その話を聞いて、笑わ**ずにはいられなかった**。（听了那话忍不住笑了）
- 彼の努力には感動せ**ずにはいられない**。

核心：**情感上无法抑制**。比 `～てしまう` 更书面、更强烈。

口语版：`～ないではいられない`。

## 09 ～ないまでも：即使不到……至少

```
动词ない形 + までも
```

- 毎日と**ないまでも**、週に一回は運動したい。（即使做不到每天，至少一周一次）
- 優勝と**ないまでも**、決勝までは行きたい。

核心：**降低要求**。前项是理想值，后项是底线。

## 10 ～いかんにかかわらず：无论……如何

```
名词（の）+ いかんにかかわらず / いかんによらず
```

- 理由の**いかんにかかわらず**、遅刻は認められない。（不管什么理由，迟到都不允许）
- 結果の**いかんによらず**、報告する義務がある。

相关家族：

| 形式 | 意思 |
|---|---|
| ～いかんにかかわらず | 无论……如何 |
| ～いかんによって | 根据……如何 |
| ～いかんだ | 取决于…… |

## 本讲小结

N1 长句的读法：

1. 先找**句末**（结论在哪）
2. 再找**句型标记**（つつある、べく、かねる……）
3. 每个标记都是一个「语气开关」，标出来句子就分层了

## 记忆卡片

> **つつある** 缓慢不可逆的变化
> **かねる** 难以（拒绝）；**かねない** 有可能（负面）
> **がたい** 心理难；**にくい** 客观难；**づらい** 难受
> **ないまでも** 降低要求
