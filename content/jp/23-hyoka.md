N1 阅读常考「作者态度」。而态度往往藏在**评价类句型**里。

这一讲处理十个决定「态度」的句型。它们不只是语法点，是文章的**价值判断开关**。

## 本讲导读

| # | 知识点 | 一句话 |
|---|--------|--------|
| 01 | ～に足る | 值得 |
| 02 | ～に値する | 值得（更书面） |
| 03 | ～に堪えない | 不堪 / 不胜 |
| 04 | ～を皮切りに | 以……为开端 |
| 05 | ～を踏まえて | 基于（前提） |
| 06 | ～に至るまで | 甚至到 |
| 07 | ～までもなく | 不必 |
| 08 | ～までだ | 只是……罢了 |
| 09 | ～なりに | 以……的方式 |
| 10 | ～だけのことはある | 确实有两下子 |

## 01 ～に足る：值得

```
名词 / 动词辞书形 + に足る
```

- 信頼**に足る**人物だ。（值得信赖的人）
- 読む**に足る**本。（值得一读的书）

⚠️ 否定形 `に足りない`（不值得）用得更多：

- 取る**に足りない**問題だ。（不值得计较的问题）

## 02 ～に値する：值得（更书面）

```
名词 / 动词辞书形 + に値する
```

- 賞賛**に値する**行為。（值得赞赏的行为）
- 一読**に値する**。（值得一读）

和 `に足る` 几乎同义，但 `に値する` 更「文雅」，常用于评价作品、行为、功绩。

固定搭配：`評価に値する`、`尊敬に値する`、`一読に値する`。

## 03 ～に堪えない：不堪 / 不胜

有两种完全不同的意思：

**① 不堪（负面承受不住）**
- その光景は見る**に堪えない**。（那景象不忍直视）

**② 不胜（正面情感满溢）**
- ご厚意、感謝**に堪えません**。（对您的厚意不胜感激）

判断靠搭配：`見るに堪えない`、`聞くに堪えない` 是负面；`感謝に堪えない`、`同情に堪えない` 是正面。

## 04 ～を皮切りに：以……为开端

```
名词 + を皮切りに（して）
```

- 東京公演**を皮切りに**、全国ツアーが始まる。（以东京公演为开端，全国巡演开始）
- 彼の成功**を皮切りに**、多くの若者が起業した。

核心：**一连串同类事件的第一件**。后面通常接**同类的多个事件**。

## 05 ～を踏まえて：基于（前提）

```
名词 + を踏まえて
```

- 前回の反省**を踏まえて**、計画を立て直した。（基于上次的反思，重新制定了计划）
- 調査結果**を踏まえた**上で、判断する。

和 `に基づいて` 的区别：

| 形式 | 语感 |
|---|---|
| に基づいて | 以……为依据（客观） |
| を踏まえて | 把……纳入考量（主观综合） |

## 06 ～に至るまで：甚至到

```
名词 + に至るまで
```

- 衣類**に至るまで**、すべて手作りだ。（甚至连衣服都是手工的）
- 小学生**に至るまで**、スマホを持っている。

核心：**范围之广，到了意想不到的程度**。常和 `から` 呼应：`AからBに至るまで`。

## 07 ～までもなく：不必

```
动词辞书形 + までもなく
```

- 言う**までもなく**、彼が犯人だ。（不用说，他就是犯人）
- 説明する**までもなく**、明らかだ。

核心：**「连……都不必」**，因为太显然了。常和 `言う`、`説明する` 搭配。

## 08 ～までだ：只是……罢了

```
动词辞书形 + までだ（= までのことだ）
```

- 失敗したら、またやる**までだ**。（失败了，再干一次就是了）
- 聞かれたから答えた**までだ**。（只是因为被问了才回答罢了）

核心：**把事情的严重性降到最低**，语气干脆、带一点「没什么大不了」。

还有一种用法：`～までだ` 表示「只有这个选择」：

- ここまで来たら、やる**までだ**。（到这一步了，只能干）

## 09 ～なりに：以……的方式

```
名词 + なりに
```

- 子ども**なりに**考えている。（孩子有孩子的想法）
- 私**なりに**努力しました。（我以我的方式努力了）

核心：**「虽然不够好，但符合那个身份/水平」**。常带一种温和的肯定。

## 10 ～だけのことはある：确实有两下子

```
普通形 + だけのことはある
名词 + だけのことはある
```

- さすが一流ホテル**だけのことはある**。（不愧是一流酒店）
- 十年練習した**だけのことはある**。（练了十年确实不一样）

和 `だけあって` 几乎是同一个意思，但 `だけのことはある` **更强调结果**（果然名副其实）。

---

## 本讲小结

| 句型 | 态度 |
|---|---|
| に足る / に値する | 肯定（值得） |
| に足りない | 贬低（不值得） |
| に堪えない | 极端（受不了 / 不胜） |
| だけのことはある | 认可（名副其实） |
| までだ | 淡化（不过如此） |
| なりに | 温和肯定（以他的方式） |

读文章时，这些地方**几乎一定是考点**——因为它们承载了作者的评价。

## 记忆卡片

> **に足る / に値する** 都是「值得」，后者更文雅
> **に堪えない** 有两种方向，看搭配
> **を皮切りに** 后面一定跟着一串同类事件
> **までだ** 是把事情说小
