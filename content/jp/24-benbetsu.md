日语有一类题目，你每个词都认识，就是选不对。原因不是不努力，是这些表达**中文翻译一模一样**。

这一讲挑出十五组最高频的，每一组只讲**判据**——不问「什么意思」，只问「什么时候用它」。

## 本讲导读

|---|---|---|

| 02 | だけ / ばかり / しかない | 客观 / 抱怨 / 不足 |
| 03 | はずだ / べきだ / わけだ | 推测 / 义务 / 必然 |
| 04 | ようだ / そうだ / らしい | 观察 / 眼见 / 听说 |
| 05 | ながら / つつ | 口语 / 书面 |
| 06 | あげく / 末に / 結果 | 消极 / 中性 / 客观 |
| 07 | につれて / にしたがって / とともに | 自然 / 遵照 / 书面对等 |
| 08 | てある / ている | 有人做 / 自然状态 |

## 01 ために vs ように：意志 vs 非意志

| | 接续 | 特点 |
|---|---|---|
| ために | 辞书形 / 名词+の | **意志性**：自己主动努力 |
| ように | 可能形 / ない形 | **非意志**：祈愿、自然达成 |

- 合格する**ために**、毎日勉強する。（为了考过，每天学习）
- 忘れない**ように**、メモする。（为了不忘记，记笔记）

判据一句话：**「我能控制」用 ために，「我希望它别发生/能发生」用 ように。**

所以 `できるように` 永远用 ように，因为「能不能」不完全由意志决定。

## 02 だけ vs ばかり vs しかない

| 形式 | 语感 | 例 |
|---|---|---|
| だけ | 客观限定 | 水**だけ**飲む（只喝水） |
| ばかり | 主观抱怨 | 文句**ばかり**言う（净抱怨） |
| しかない | 不足・无奈 | 百円**しか**ない（只有一百日元） |

`しか` 后面**必须接否定**，这是硬规则。

三者都能译成「只有」，但：

- `だけ` 中性陈述
- `ばかり` 带负面评价
- `しかない` 带「不够/没办法」

## 03 はずだ vs べきだ vs わけだ

| 形式 | 依据 | 中文 |
|---|---|---|
| はずだ | 逻辑推测 | 应该（按理说） |
| べきだ | 道义义务 | 应该（必须） |
| わけだ | 因果必然 | 难怪 / 也就是说 |

- 彼はもう着いた**はずだ**。（他应该到了——推测）
- 謝る**べきだ**。（应该道歉——义务）
- なるほど、そういう**わけ**か。（原来如此——难怪）

## 04 ようだ / そうだ / らしい：信息来源

| 形式 | 信息来自 |
|---|---|
| ようだ | 自己的五感观察 |
| そうだ（样态） | 眼前的样子 |
| そうだ（传闻） | 别人说的 |
| らしい | 听说 + 自己判断 |

同一句「要下雨了」：

- 空が暗い。雨が降り**そうだ**。（看天，要下了）
- 天気予報によると、降る**そうだ**。（预报说）
- 雨が降る**らしい**。（听说是）
- 雨が降っている**ようだ**。（看外面，好像在下）

## 05 ながら vs つつ

| | 语体 | 其它用法 |
|---|---|---|
| ながら | 口语 | 逆接（残念ながら） |
| つつ | 书面 | 逆接（知りつつ） + つつある |

几乎是同一个意思，选择只看**文体**。写文章用 つつ，说话用 ながら。

## 06 あげく vs 末に vs 結果

| 形式 | 结果倾向 |
|---|---|
| あげく | **消极**（折腾半天，没好事） |
| 末に | 中性偏客观（经过长时间） |
| 結果 | 纯客观 |

- さんざん悩んだ**あげく**、やめた。（纠结半天，最后放弃了——消极）
- 考えた**末に**、決断した。（深思熟虑后决定了——中性）
- 調査した**結果**、問題がわかった。（调查结果，发现了问题——客观）

## 07 につれて / にしたがって / とともに

| 形式 | 特点 |
|---|---|
| につれて | 自然连带变化（最常用） |
| にしたがって | 还能表示「遵照」 |
| とともに | 书面，也表示「和……一起」 |

- 年を取る**につれて**、体力が落ちる。
- 規則**にしたがって**、手続きをする。（遵照规则——只有它能这么用）
- 経済の発展**とともに**、環境問題も深刻になった。

## 08 てある vs ている

| 形式 | 谁做的 | 例 |
|---|---|---|
| てある | 有人刻意做了 | 窓が開け**てある** |
| ている | 不问原因 | 窓が開い**ている** |

判据：**「这是谁弄的」重要吗？** 重要 → てある；不重要 → ている。

⚠️ てある 前面必须是**他动词**（開ける、貼る、並べる）。

## 09 ようになる vs ようにする

- 日本語が話せる**ようになった**。（能力变了）
- 毎朝走る**ようにしている**。（我在努力养成习惯）

**なる 是变，する 是做。** 这一条能解决 80% 的题目。

## 10 ものだ vs ものか vs ことだ

| 形式 | 功能 | 例 |
|---|---|---|
| ものだ | 感叹本性/常理 | 時間が経つのは早い**ものだ** |
| ものか | 强烈反问（否定） | 負ける**ものか**（谁会输） |
| ことだ | 直接忠告 | 失敗を恐れない**ことだ** |

三个长得像，功能完全不同：感叹、反问、建议。

## 11 次第 vs たら

| 形式 | 语体 | 后句 |
|---|---|---|
| 次第 | 正式书面 | 意志行为（連絡します） |
| たら | 口语通用 | 不限 |

- 確認でき**次第**、ご連絡いたします。（商务邮件）
- 確認でき**たら**、連絡するね。（日常）

## 12 かねる vs かねない

这是一对「长得像双胞胎，意思正好相反」的经典陷阱：

| 形式 | 意思 | 例 |
|---|---|---|
| かねる | 难以做到（拒绝） | 賛成し**かねます** |
| かねない | 有可能（负面） | 事故になり**かねない** |

记忆钩子：**加个「ない」就反过来了**。

## 13 わけではない vs ものではない

| 形式 | 功能 | 例 |
|---|---|---|
| わけではない | 部分否定 | 嫌いな**わけではない**（不是讨厌） |
| ものではない | 道义否定 | 人の悪口を言う**ものではない** |

前者是**逻辑上的否定**，后者是**规范上的否定**。

## 14 あげる / くれる / もらう

| 方向 | 动词 |
|---|---|
| 我 → 别人 | あげる |
| 别人 → 我 | くれる |
| 我 ← 别人（我主动） | もらう |

⚠️ 方向错一个，**恩情关系就整个反转**。这是日语最不容错的语法。

## 15 自动词 / 他动词

日语动词大量成对出现：

| 自动词（状态） | 他动词（动作） |
|---|---|
| 開く | 開ける |
| 閉まる | 閉める |
| 落ちる | 落とす |
| 沸く | 沸かす |
| 始まる | 始める |

判据：

- 描述**现状** → 自动词 + ている（窓が開いている）
- 描述**谁干的** → 他动词（窓を開けた）

## 本讲小结

十五组看着多，其实归成三类：

1. **信息来源不同**（ようだ・そうだ・らしい・はずだ）
2. **意志介入程度不同**（ために・ように・てある・ている）
3. **情绪态度不同**（あげく・だけ・ばかり・かねる）

第二类最难，因为中文里「打算」「状态」不分。

## 记忆卡片

> **ために** 意志；**ように** 非意志
> **だけ** 客观；**ばかり** 抱怨；**しかない** 不足
> **かねる** 拒绝；**かねない** 可能
> **なる** 变；**する** 做
