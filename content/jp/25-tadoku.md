学日语到某个阶段，会遇到一个奇怪的瓶颈：**语法都看得懂，文章就是读不完**。

原因很简单——你一直在「精读」，从没「多读」。精读练的是拆解能力，多读练的是**处理速度**。N2 读解考的不是你能不能懂，而是**你在 70 分钟里能懂多少**。

多读（多読 / tadoku）就是为这件事发明的。

## 01 多读是什么

多读的官方定义（NPO 多言語多読）：

> **从能看懂的书开始，大量地读。因为读得懂而觉得有趣，因为有趣而读得更多。**

听起来像鸡汤，但它背后是一套很硬的语言学习逻辑：**输入量决定处理速度**。你读过的句子结构越多，下次见到就越不需要「分析」。

## 02 四条铁律

这是多读的全部方法论，没有第五条：

1. **从简单的书读起**——低于自己水平 1～2 级才叫入门
2. **不查词典**——猜意思，猜不出就跳过
3. **读不懂的地方跳过去**——完整的故事不等于逐句精读
4. **读不动了就换一本**——绝不在一本书上卡死

第三条和第四条最反直觉，也最重要。**中国人的阅读习惯是「必须每句都懂」，这个习惯必须暂时放下。**

## 03 为什么有效

因为多读建立的是一条**正循环**：

```
读得懂 → 有趣 → 想读更多 → 读得更多 → 读得更快 → 更读得懂
```

而精读建立的常常是**负循环**：

```
查词典 → 打断 → 累 → 读得少 → 慢 → 更累
```

N2 读解的时间压力，只能靠第一条循环解决。

## 05 你的起点

如果你正在刷 N2 语法 + 词汇：

> **Level Start / 0 当热身周一口气读完 → 主攻 Level 2–3 → 冲 Level 4。**

**别从 Level 4 开始硬啃，那是劝退路线。** 多读的核心是「轻松」，一旦变成苦读，方法就失效了。

## 08 记录法：一行一本

每读完一本，记一行：

```
书名 / 用时 / 生词数 / 一句话感想
```

30 天后你会有一张 100+ 行的表。这张表有两个作用：

1. **量化进步**：同一本书第二遍读，用时会掉一半
2. **心理支撑**：考前看它，比看任何鸡汤都有用

## 09 和语法怎么配：两条腿走路

很多人以为「多读就不用学语法」——这是误解。

| | 多读 | 语法 |
|---|---|---|
| 练什么 | 处理速度、语感 | 结构理解、精确度 |
| 怎么练 | 大量、不查、跳过 | 少量、精析、对比 |
| 缺了会怎样 | 读得懂但慢 | 读得快但不准 |

**最佳配比：每天 20 分钟多读 + 30 分钟语法**。多读负责「量」，语法负责「质」。

## 10 三个常见误区

**误区一：觉得书太幼稚**

`あっ、まるい` 这种书确实像幼儿园读物。但你要练的不是「读懂内容」，是「读的速度」。**允许自己幼稚，是成年学习者最难的一步。**

**误区二：偷偷查词典**

查一次，节奏就断了。真想查，拿张纸记下页码，读完再查。

**误区三：一本书读不完就不舒服**

多读的规则是「读不动就换」。**放弃一本书不是失败，是方法的一部分。**

## 本讲小结

多读不是「多读书」的意思，而是**一套刻意降低难度的阅读训练**。它的目标只有一个：让你在 N2 考场上，**眼睛比脑子快**。

## 记忆卡片

> **四条铁律**：简单起步、不查词典、跳过不懂、读不动就换
> **起点**：比你的水平低 1–2 级
> **配比**：20 分钟多读 + 30 分钟语法
> **目标**：不是读懂，是读快
