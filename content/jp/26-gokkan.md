语法错，日本人会想「他在学日语」。语感错，日本人会想「他不太懂我们」。

这一讲的十组词，语法上都对，但**用错场合会让人不舒服**。它们比语法更难，因为词典不告诉你答案。

## 01 だんだん vs どんどん：慢 vs 猛

两个都是「越来越」，区别在**速度感**。

**だんだん** 来自「階段（かいだん）」的「段々」，本义是**一级一级往上/往下爬**，所以带「缓慢、逐步」的感觉。

- だんだん暑くなった。（渐渐热起来了）
- だんだん暗くなった。（渐渐暗了）

温度变化的感觉：

```
20° → 22° → 24° → 26° → 28° → 30°
```

**どんどん** 来自太鼓「咚咚」的拟声，带**猛烈、连续、不中断**的感觉。

- どんどん暑くなった。（越来越热）
- 客がどんどん来る。（客人接连不断地来）
- ドアをどんどん叩く。（咚咚地敲门）

同一件事的温度变化：

```
25° → 30° → 35°
```

一句话：**だんだん 是爬楼梯，どんどん 是坐电梯。**

## 02 すぐ / もうすぐ / 間もなく

| 词 | 侧重 | 例 |
|---|---|---|
| すぐ | 距离近 + 时间短 | すぐ行きます（马上就去） |
| もうすぐ | 时间即将到来 | もうすぐ春ですね |
| 間もなく | 书面、正式 | 間もなく電車が参ります |

`すぐ` 还能指**空间距离**：`駅はすぐそこです`（车站就在那儿）。

`間もなく` 基本只出现在**广播、通知、文章**里。你在电车里听到的「まもなく〜」就是它。

## 03 とても / 非常に / かなり / 大変

| 词 | 语体 | 特点 |
|---|---|---|
| とても | 口语 | 最常用，不能随便接否定 |
| 非常に | 书面/正式 | 报告、演讲 |
| 大変 | 正式 | 也可作形容词（辛苦） |
| かなり | 中性 | 客观「相当」 |
| 相当 | 口语 | 「挺」 |

⚠️ `とても` 接否定的特殊用法：

- とても～ない = **怎么也不**（不是「不太」）
- とても行けない。（怎么也去不了）

而「不太」要用 `あまり` 或 `そんなに`。

## 04 お疲れ様 vs ご苦労様

这是日语敬语里最实用的一条：

| 说法 | 谁对谁说 |
|---|---|
| お疲れ様（です） | 平级、对上级、对任何人（万能） |
| ご苦労様（です） | **只能上级对下级** |

⚠️ 对上司说「ご苦労様」是**明显失礼**，因为它暗示「我比你高」。

反过来，`お疲れ様です` 几乎万能：

- 同事下班：お疲れ様です
- 对上司：お疲れ様です（也可以）
- 邮件开头：お疲れ様です

## 05 ありがとうございます vs ありがとうございました

原则：

| 形式 | 用于 |
|---|---|
| ありがとうございます | 恩惠**正在进行 / 持续** |
| ありがとうございました | 恩惠**已经结束** |

- （收到礼物当场）ありがとうございます。
- （事办完了，道别时）ありがとうございました。

实际上现代日语里两者常混用，但**原则记住就不会错**：**还在受益 → ます；事情结束 → ました**。

## 06 ないで vs なくて

这两个都来自「ない」，但功能完全不同：

| 形式 | 功能 | 例 |
|---|---|---|
| ないで | 不做某事（替代て）/ 状态 | 朝ご飯を食べ**ないで**学校へ行った |
| なくて | 原因 / 并列（形容词性） | お金が**なくて**買えなかった |

判据：

- **后面是「怎么做的」→ ないで**
- **后面是「为什么」→ なくて**

- 傘を持た**ないで**出かけた。（没带伞就出门了——方式）
- 傘が**なくて**困った。（因为没伞而困扰——原因）

## 07 こと vs 件

| 词 | 范围 | 例 |
|---|---|---|
| こと | 抽象的事、事情 | 大変なことになった |
| 件 | 具体的案件、事项 | その件について話したい |

`件` 是**商务日语的关键词**：

- 例の件（那件事——特指双方都知道的具体事项）
- 件の人物（那个人物——新闻用语）

日常说话用 `こと`，工作场合提到具体事务用 `件`。

## 08 する vs やる

| 词 | 语体 | 备注 |
|---|---|---|
| する | 中性 | 几乎所有场合 |
| やる | 口语 | 也可表示「给」（やる） |

- 宿題を**する**（做作业——标准）
- 宿題を**やる**（做作业——随意）

`やる` 还有个古一点的用法是「给（动植物/下级）」：

- 花に水を**やる**（给花浇水）
- 犬に餌を**やる**（给狗喂食）

这两个现在都还常用，但**对人不能用やる**（失礼）。

## 09 せっかく vs わざわざ

| 词 | 语感 |
|---|---|
| せっかく | 好不容易（常带惋惜） |
| わざわざ | 特意（不嫌麻烦） |

- **せっかく**来たのに、店は閉まっていた。（好不容易来了，店却关了——惋惜）
- **わざわざ**来てくださって、ありがとうございます。（特意跑来，谢谢——感谢）

`せっかく` 后面常接 `のに`、`から`、`だから`，`わざわざ` 后面常接感谢。

## 10 つまらない / 退屈 / くだらない

三个都能译成「无聊」，但完全不同：

| 词 | 意思 | 例 |
|---|---|---|
| つまらない | 没意思、没价值 | つまらない話（没意思的话） |
| 退屈 | 闲得难受（时间难熬） | 退屈で死にそう（无聊得要死） |
| くだらない | 没意义、低级 | くだらないことで喧嘩する |

判据：

- 事情本身没价值 → **つまらない**
- 你有时间但没事干 → **退屈**
- 事情毫无意义甚至低俗 → **くだらない**

## 本讲小结

这十组的共同点：**中文都只有一个词，日语按「场合、语体、情绪」分开。**

学这类词，最好的方法不是背定义，而是**收集例句**：看到一个词，记下它出现的场景（谁对谁说、什么情绪）。三次之后，语感就长出来了。
